# GRE Quant — Concept Capsules

A complete concept repository for GRE Quantitative Reasoning: **75 capsules** across 9 sections.

Each capsule is a self-contained handout in the same 7-part format, so students always know where to look:

1. **Core Idea** — the one thing to understand
2. **Must-Know Rules** — formulas and facts in tables
3. **Worked Examples** — 3 fully solved problems
4. **GRE Traps** — the specific mistakes students make
5. **Speed Tricks** — shortcuts that save exam time
6. **Self-Check** — 3 questions with collapsible answers
7. **One-Line Summary for the Board** — what to write on the whiteboard

Math is written in plain text (e.g. `(a+b)^2 = a^2 + 2ab + b^2`) so the notes read correctly anywhere — printed, in Notion, over WhatsApp, or in any markdown viewer.

**Bank codes** in each capsule header map to the subtopic IDs in the GRE Quant Pro question bank, so a concept note and its practice set line up.

## Suggested Teaching Order

A 12-week course, two capsules per class:

| Weeks | Focus |
|---|---|
| 1-2 | Arithmetic 1-5 (percentages, fractions, ratios, exponents, rates) |
| 3 | Number Properties 1-4 (factors, primes, divisibility, GCD/LCM) |
| 4-5 | Algebra 1-6 (expressions through quadratics) |
| 6 | Algebra 7-9 + Arithmetic 6-10 |
| 7-8 | Word Problems 1-9 |
| 9-10 | Geometry 1-14 |
| 11 | Coordinate Geometry 1-6 + Statistics 1-5 |
| 12 | Statistics 6-11, Data Interpretation 1-5, Exam Strategy 1-3 |

**Exam Strategy capsules can also be taught in week 1** — students benefit from knowing the question formats and the Quantitative Comparison method before they attempt any practice set.

## Highest-Yield Capsules

If time is short, these carry the most GRE weight:

1. Percentages
2. Quantitative Comparison — Method
3. Triangles — Fundamentals + Pythagorean Theorem
4. Algebraic Expressions & Simplification
5. Mean, Median & Mode
6. Basic Probability
7. Circles

9. Inequalities
