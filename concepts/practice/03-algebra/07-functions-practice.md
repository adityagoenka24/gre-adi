## Part C — Worked Solutions

### Q1 · `ALG-FNC-003` — Answer: 11

Step 1 — substitute. Whatever sits inside the brackets replaces every x in the rule, brackets and all: h(-2) = 2*(-2)^2 + 3.
Step 2 — square first, because the exponent binds tighter than the multiplication: (-2)^2 = 4.
Step 3 — finish: 2*4 + 3 = 8 + 3 = 11.
Check: h(2) = 2*(2)^2 + 3 = 11 as well, which is what a rule built only from x^2 and a constant must do - it cannot tell -2 from 2. Correct.
Answer: 11.

**Trap.** Dropping the brackets around the -2 and reading the rule as -(2*2^2) + 3 = -5, or as 2*(-2^2) + 3 = -5. The minus sign belongs to the input, so it is inside the square and disappears. A second error is doubling before squaring: (2*(-2))^2 + 3 = 19.

### Q2 · `ALG-FNC-005` — Answer: D

Step 1 — identify the inner function. In g(f(2)) the input to g is f(2), so f runs first.
Step 2 — evaluate the inner function: f(2) = 3*2 - 2 = 6 - 2 = 4.
Step 3 — feed that output into g: g(4) = 4^2 - 1 = 16 - 1 = 15.
Check: run the other order to confirm the two are genuinely different. g(2) = 2^2 - 1 = 3, then f(3) = 3*3 - 2 = 7, so f(g(2)) = 7, not 15. Composition is not commutative, and the stem asks for g(f(2)). Correct.
Answer: D.

**Trap.** Reversing the order and computing f(g(2)) = f(3) = 7, which is choice C. In g(f(2)) the function written on the inside acts first. Choice A, 3, is g(2) alone, applying the outer rule to the raw input and never using f; choice B, 4, is f(2) alone, stopping after the inner step; choice E, 16, is 4^2, forgetting the - 1 in the rule for g.

### Q3 · `ALG-FNC-008` — Answer: C

Step 1 — evaluate Column A: f(3) = 3^2 + 1 = 9 + 1 = 10.
Step 2 — evaluate Column B, keeping the brackets: f(-3) = (-3)^2 + 1 = 9 + 1 = 10.
Step 3 — compare: 10 and 10 are equal.
Check: the only place x appears in the rule is inside a square, and squaring destroys the sign, so f(-a) = f(a) for every a. Testing a second pair, f(2) = 5 and f(-2) = 5, confirms the pattern rather than just the one case. Correct.
Answer: C.

**Trap.** Writing f(-3) = -3^2 + 1 = -9 + 1 = -8, which makes Column A look greater and produces choice A. The input is -3, so the whole of -3 is squared. Choice D tempts anyone who assumes a negative input must change the answer without actually computing it.

### Q4 · `ALG-FNC-009` — Answer: B

Step 1 — read the definition as a template: the first entry is doubled, the second is added as it stands.
Step 2 — substitute p = 3 and q = 4: 3 # 4 = 2*3 + 4.
Step 3 — compute: 6 + 4 = 10.
Check: compute 4 # 3 the same way, 2*4 + 3 = 11. The two disagree, which is the expected behaviour - the definition treats the two slots differently, so the order cannot be swapped. Correct.
Answer: B.

**Trap.** Assuming the new symbol must be commutative like + or *, and computing 4 # 3 = 2*4 + 3 = 11, which is choice C. A made-up symbol carries no properties beyond its written definition. Choice A, 7, ignores the 2 and just adds; choice D, 14, applies the 2 to the whole sum as 2*(3 + 4); choice E, 24, multiplies all three numbers as 2*3*4.

### Q5 · `ALG-FNC-011` — Answer: A

Step 1 — cover the x in the rule with a finger. Whatever is in the brackets goes wherever the finger was, so the input 2x replaces x once, and only where x appeared.
Step 2 — substitute: f(2x) = 3*(2x) + 2 = 6x + 2.
Step 3 — note what did not change. The constant 2 is not attached to x, so doubling the input leaves it alone.
Check: take x = 5. Then 2x = 10 and f(10) = 3*10 + 2 = 32, while choice A gives 6*5 + 2 = 32. Correct.
Answer: A.

**Trap.** Confusing f(2x) with 2f(x). Doubling the output gives 2*(3x + 2) = 6x + 4, which is choice D; doubling the input gives 6x + 2. One doubles everything, the other doubles only what x multiplies. Choice B doubles the constant instead of the input; choice C substitutes 2x but forgets to carry the + 2 down; choice E doubles both the input and the output.

### Q6 · `ALG-FNC-017` — Answer: E

Step 1 — work from the inside out. The inner function is g, so evaluate g(2) first: g(2) = 3*2 - 2 = 6 - 2 = 4.
Step 2 — that output, 4, becomes the input to f: f(4) = 4^2 + 4 = 16 + 4 = 20.
Check: build the composite in general and evaluate it a second way. f(g(x)) = (3x - 2)^2 + (3x - 2) = 9x^2 - 12x + 4 + 3x - 2 = 9x^2 - 9x + 2, and at x = 2 that is 36 - 18 + 2 = 20. Correct.
Answer: E.

**Trap.** Reversing the order and computing g(f(2)) = g(2^2 + 2) = g(6) = 3*6 - 2 = 16, which is choice C. The inner function acts first. Choice A, 4, is g(2) alone, stopping after the inner step and never applying f; choice B, 12, comes from evaluating g(2) as 3, subtracting the 2 from the coefficient instead of from the product, and then f(3) = 9 + 3; choice D, 18, carries the original input into the second term of f, computing f(4) as 4^2 + 2 rather than 4^2 + 4.

### Q7 · `ALG-FNC-018` — Answer: 11

Step 1 — read f^(-1)(5) as a question, not a formula: which input does f send to 5? Solve (3x + 1)/2 = 5.
Step 2 — clear the denominator: 3x + 1 = 10, so 3x = 9 and x = 3. Therefore f^(-1)(5) = 3.
Step 3 — evaluate f in the ordinary direction: f(5) = (3*5 + 1)/2 = 16/2 = 8.
Step 4 — add: 3 + 8 = 11.
Check: verify the inverse value by running it forward. f(3) = (9 + 1)/2 = 5, which is the input to f^(-1) we started from. Correct.
Answer: 11.

**Trap.** Reading f^(-1)(5) as the reciprocal 1/f(5) = 1/8, which turns the sum into 8.125. The exponent -1 on a function name means the inverse function, not a reciprocal. A second error is inverting only part of the rule, writing f^(-1)(x) = 2x/3 + 1 and getting f^(-1)(5) = 13/3 instead of first undoing the +1 and then the division by 2.

### Q8 · `ALG-FNC-020` — Answer: B

Step 1 — evaluate Column A from the inside out. g(5) = 5 - 1 = 4, then f(4) = 2*4 + 3 = 11.
Step 2 — evaluate Column B from the inside out. f(5) = 2*5 + 3 = 13, then g(13) = 13 - 1 = 12.
Step 3 — compare: 11 is less than 12, so Column B is greater.
Check: compose in general to see that the gap is not an accident of x = 5. f(g(x)) = 2(x - 1) + 3 = 2x + 1, while g(f(x)) = (2x + 3) - 1 = 2x + 2. The second exceeds the first by 1 for every x, so Column B is greater no matter what number the stem had used. Correct.

**Trap.** Assuming the two columns must be equal because the same two functions and the same input appear in both, and answering C. Order changes the result: subtracting 1 before doubling removes 2 from the final total, while subtracting 1 after doubling removes only 1. Answering D on the grounds that composition order is unpredictable is the other error; both columns are fully determined here.

### Q9 · `ALG-FNC-023` — Answer: A, D, E

Step 1 — state the restriction. A square root is defined only when what sits under it is greater than or equal to 0, so g(x) is defined exactly when x^2 - 4 >= 0.
Step 2 — test each option by computing f(x) first.
A. x = -3: f(-3) = 9 - 4 = 5, and sqrt(5) is defined. TRUE.
B. x = -1: f(-1) = 1 - 4 = -3, and sqrt(-3) is not a real number. FALSE.
C. x = 0: f(0) = 0 - 4 = -4, and sqrt(-4) is not a real number. FALSE.
D. x = 2: f(2) = 4 - 4 = 0, and sqrt(0) = 0, which is perfectly defined. TRUE.
E. x = 3: f(3) = 9 - 4 = 5, and sqrt(5) is defined. TRUE.
Check: the condition x^2 >= 4 means the distance from x to 0 is at least 2, so the allowed inputs are x <= -2 together with x >= 2. Of the five listed values, -3, 2 and 3 satisfy that and -1 and 0 do not, which matches the option-by-option work. Correct.
Answer: A, D and E.

**Trap.** Excluding D on the grounds that the square root needs a strictly positive input. sqrt(0) = 0 is defined; only a negative radicand is barred, so the boundary value x = 2 belongs in the answer. The opposite error is reading the restriction as a condition on x rather than on f(x) and keeping every x with x >= 0, which wrongly admits C.

### Q10 · `ALG-FNC-025` — Answer: C

Step 1 — evaluate Column A: f(-4) = (-4)^2 + 2*(-4) + 1 = 16 - 8 + 1 = 9.
Step 2 — evaluate Column B: f(2) = 2^2 + 2*2 + 1 = 4 + 4 + 1 = 9.

**Trap.** Assuming the larger input must give the larger output and answering B, or assuming the negative input must give the smaller output and answering A. ### Q12 · `ALG-FNC-027` — Answer: D

Step 1 — use the one value you are given to recover the hidden constant. f(3) = 2*3 + k = 6 + k, and that equals 11.

### Q13 · `ALG-FNC-061` — Answer: B

Step 1 — handle the vertical shift, which behaves the way it reads. Moving the graph up 5 adds 5 to every output, so h(x) = (something) + 5. That rules out C and D.
