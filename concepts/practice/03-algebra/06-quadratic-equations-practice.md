## Part C — Worked Solutions

### Q1 · `ALG-QDR-007` — Answer: B

Step 1 — read off a, b and c. Here a = 1, b = -6, c = 9.
Step 2 — apply D = b^2 - 4ac. D = (-6)^2 - 4(1)(9) = 36 - 36 = 0.
Step 3 — read the discriminant. D = 0 means the two roots coincide, so there is exactly one distinct real solution.
Check: x^2 - 6x + 9 = (x - 3)^2, so the only solution is x = 3, and substituting back gives 9 - 18 + 9 = 0. Correct.
Answer: B.

**Trap.** Computing b^2 and stopping there gives D = 36 and the report of two distinct roots, choice D — the -4ac term is half the formula. Adding instead of subtracting gives 36 + 36 = 72, choice E. Choice C confuses D = 0 with D < 0: zero is the boundary where the two roots merge into one, not where they disappear, and choice A forgets that they merge at all.

### Q2 · `ALG-QDR-008` — Answer: D

Step 1 — the equation is already equal to zero, so factor instead of dividing. x^2 + 3x = x(x + 3).
Step 2 — apply the zero-product property to x(x + 3) = 0: either x = 0 or x + 3 = 0.
Step 3 — solve each factor. x = 0, and x + 3 = 0 gives x = -3.
Check: 0^2 + 3(0) = 0. Correct. And (-3)^2 + 3(-3) = 9 - 9 = 0. Correct.
Answer: D.

**Trap.** Dividing both sides by x turns x^2 + 3x = 0 into x + 3 = 0 and reports x = -3 only, choice A — the root x = 0 is destroyed by the division, because dividing by x assumes x is not 0. Choice E flips the sign when solving x + 3 = 0, reading it as x = 3. Choice B keeps only the first factor and stops. Choice C makes both mistakes at once.

### Q3 · `ALG-QDR-012` — Answer: D

Step 1 — solve x^2 = 16. Taking the square root of both sides gives x = 4 or x = -4. The stem says x > 0, so x = 4.
Step 2 — solve y^2 = 25 the same way: y = 5 or y = -5. Nothing in the stem restricts the sign of y, so both survive.
Step 3 — evaluate Quantity A in each case. If y = 5, then x + y = 4 + 5 = 9, equal to Quantity B. If y = -5, then x + y = 4 - 5 = -1, less than Quantity B.
Check: 4^2 = 16 and 4 > 0; 5^2 = 25 and (-5)^2 = 25. Both values of y are legal, and they give different comparisons.
Answer: D.

**Trap.** Taking only the positive square root of y^2 = 25 gives y = 5, Quantity A = 9, and the confident answer C. The condition x > 0 is stated for x and deliberately not stated for y; a squared variable carries two roots until something in the stem removes one.

### Q4 · `ALG-QDR-010` — Answer: 17

Step 1 — match to ax^2 + bx + c = 0: a = 1, b = -7, c = 10.
Step 2 — sum of roots = -b/a = -(-7)/1 = 7.
Step 3 — product of roots = c/a = 10/1 = 10.
Step 4 — p + q + pq = 7 + 10 = 17.
Check by solving: x^2 - 7x + 10 = (x - 2)(x - 5), so the roots are 2 and 5. Then p + q = 7, pq = 10, and 7 + 10 = 17. Correct.
Answer: 17.

**Trap.** Writing the sum of roots as b/a instead of -b/a gives -7, and then -7 + 10 = 3. The minus sign in -b/a is the single most-dropped sign in this topic. A second error is reading the product as -c/a, which gives 7 - 10 = -3.

### Q5 · `ALG-QDR-015` — Answer: A, D, E

Use D = b^2 - 4ac. Two distinct real solutions requires D > 0 strictly.
A — x^2 - 5x + 6: D = 25 - 24 = 1 > 0. TRUE. (The roots are 2 and 3.)
B — x^2 + 4x + 4: D = 16 - 16 = 0. FALSE — this is (x + 2)^2, one repeated root x = -2, not two distinct ones.
C — x^2 + x + 1: D = 1 - 4 = -3 < 0. FALSE — no real solutions at all.
D — x^2 - 8: here b = 0 and c = -8, so D = 0 - 4(1)(-8) = 32 > 0. TRUE. (The roots are sqrt(8) and -sqrt(8).)
E — 2x^2 - 3x - 2: D = 9 - 4(2)(-2) = 9 + 16 = 25 > 0. TRUE. (The roots are 2 and -1/2.)
Answer: A, D and E.

**Trap.** Choice B is the standard miss: D = 0 gets counted as 'real solutions exist', which is true but not the question — the equation has one solution, not two distinct ones. Choice D is missed in the other direction: with no x term students read b as absent and forget that b = 0 still makes D = -4ac = 32, which is positive because c is negative.

### Q6 · `ALG-QDR-021` — Answer: C

Step 1 — the question asks for x, but the only thing given about x is a condition on k, so pin k down first.
Step 2 — exactly one real solution means the discriminant is zero, not positive and not negative. With a = 1, b = k, c = 25: D = k^2 - 4(1)(25) = k^2 - 100.
Step 3 — set D = 0: k^2 = 100, so k = 10 or k = -10. The stem pins k < 0, so k = -10.
Step 4 — substitute that k back: x^2 - 10x + 25 = 0, which is the perfect square (x - 5)^2 = 0.
Step 5 — the repeated root is x = 5.
Faster route once you recognise the pattern: when D = 0 the single root is always x = -b/(2a), here -(-10)/2 = 5, with no factoring needed.
Check: 5^2 - 10(5) + 25 = 25 - 50 + 25 = 0, and the discriminant is 100 - 100 = 0, so 5 really is the only solution. Correct.
Answer: C.

**Trap.** Choice B is the main trap: taking the k = +10 branch despite the stem's k < 0 gives (x + 5)^2 = 0 and the root -5. Half the work of this question is noticing that the sign condition selects a branch. Choice A reports k itself instead of the solution, and choice D reports |k|. Choice E comes from writing D = k^2 - 25, using c rather than 4ac, then reading the constant term off as the answer.

### Q7 · `ALG-QDR-025` — Answer: E

Step 1 — collect everything on one side first. x^2 = 2x + 1 becomes x^2 - 2x - 1 = 0. Nothing can be read off until this is done.
Step 2 — identify a = 1, b = -2, c = -1. This trinomial does not factor over the integers, so use the formula.
Step 3 — D = b^2 - 4ac = (-2)^2 - 4(1)(-1) = 4 + 4 = 8.
Step 4 — x = [-b +/- sqrt(D)] / (2a) = [2 +/- sqrt(8)] / 2.
Step 5 — sqrt(8) = 2*sqrt(2), so x = (2 +/- 2*sqrt(2)) / 2 = 1 +/- sqrt(2). Divide EVERY term of the numerator by 2.
Check x = 1 + sqrt(2) in the original: left side (1 + sqrt(2))^2 = 1 + 2*sqrt(2) + 2 = 3 + 2*sqrt(2); right side 2(1 + sqrt(2)) + 1 = 3 + 2*sqrt(2). Equal. Check x = 1 - sqrt(2): left side = 3 - 2*sqrt(2); right side = 2 - 2*sqrt(2) + 1 = 3 - 2*sqrt(2). Equal.
Answer: E.

**Trap.** Not setting the equation to zero and reading b = 2, c = 1 straight off 'x^2 = 2x + 1' gives D = 4 - 4 = 0 and the single answer x = -1, choice A. Choice C drops the minus in -b and uses -2/2. Choice D divides only the radical by 2a and leaves the 2 alone, turning (2 +/- 2*sqrt(2))/2 into 2 +/- sqrt(2). Choice B keeps only the plus branch.

### Q8 · `ALG-QDR-033` — Answer: B

Step 1 — this is a quadratic in disguise. Let u = x^2; then x^4 = u^2 and the equation becomes u^2 - 13u + 36 = 0.
Step 2 — factor: two numbers with product 36 and sum -13 are -4 and -9, so (u - 4)(u - 9) = 0 and u = 4 or u = 9.
Step 3 — undo the substitution. u = x^2, so x^2 = 4 gives x = 2 or x = -2, and x^2 = 9 gives x = 3 or x = -3.
Step 4 — a degree-4 equation can have up to four real roots, and here all four are real.
Check x = -3 in the original: (-3)^4 - 13(-3)^2 + 36 = 81 - 117 + 36 = 0. Correct. Check x = 2: 16 - 52 + 36 = 0. Correct.
Answer: B.

**Trap.** Stopping at u = 4 and u = 9 and reporting those as the values of x gives choice D — the substitution has to be undone. Choice E undoes it by attaching a plus-or-minus to 4 and 9 instead of square-rooting them. Choice A square-roots correctly but keeps only the positive root of each, losing half the solution set; choice C solves only the u = 4 branch.

### Q9 · `ALG-QDR-037` — Answer: C

Step 1 — factor the leading coefficient out of the x terms only: 2x^2 - 12x + 23 = 2(x^2 - 6x) + 23.
Step 2 — complete the square inside the bracket. Half of -6 is -3, and (-3)^2 = 9, so x^2 - 6x = (x - 3)^2 - 9.
Step 3 — substitute back, remembering the 2 multiplies BOTH pieces: 2[(x - 3)^2 - 9] + 23 = 2(x - 3)^2 - 18 + 23 = 2(x - 3)^2 + 5.
Step 4 — (x - 3)^2 is never negative and equals 0 at x = 3, so the smallest the expression can be is 5.
Check at x = 3: 2(9) - 12(3) + 23 = 18 - 36 + 23 = 5. Check a neighbour, x = 4: 32 - 48 + 23 = 7, which is larger. Correct.
Answer: C.

**Trap.** Reporting x = 3, the location of the minimum, instead of the minimum value itself gives choice B. Choice D comes from writing 2(x - 3)^2 - 9 + 23 and subtracting the 9 once instead of twice. Choice A subtracts 4 times 9 instead of 2 times 9: 23 - 36 = -13. Choice E is the value at x = 0, which is the y-intercept, not the minimum.

### Q10 · `ALG-QDR-026` — Answer: A

Step 1 — 'no real solutions' is exactly the statement D < 0.
Step 2 — with a = 1, b = 4, c = k: D = 4^2 - 4(1)(k) = 16 - 4k.
Step 3 — impose 16 - 4k < 0, so 16 < 4k and k > 4.
Step 4 — every legal k is strictly greater than 4, so Quantity A is greater for every value the stem allows.
Check k = 5: x^2 + 4x + 5 has D = 16 - 20 = -4 < 0, no real roots, and 5 > 4. Check the boundary k = 4: x^2 + 4x + 4 = (x + 2)^2 has the real root x = -2, so k = 4 is not allowed and the inequality is strict.
Answer: A.

**Trap.** Dividing 16 - 4k < 0 by -4 without reversing the inequality gives k < 4 and the answer B. A second route to B is treating D < 0 as 'k must be small', which reverses the actual logic: a larger constant term lifts the parabola clear of the x-axis. Answering C on the boundary case k = 4 ignores that D = 0 there produces a real root, which the stem forbids.

### Q11 · `ALG-QDR-024` — Answer: 19

Step 1 — do not solve for the roots; they are irrational. Use Vieta. p + q = -b/a = 5 and pq = c/a = 3.
Step 2 — use the identity (p + q)^2 = p^2 + 2pq + q^2, so p^2 + q^2 = (p + q)^2 - 2pq.
Step 3 — substitute: p^2 + q^2 = 5^2 - 2(3) = 25 - 6 = 19.
Check the long way: the roots are (5 +/- sqrt(13))/2. Their squares are (25 + 10*sqrt(13) + 13)/4 and (25 - 10*sqrt(13) + 13)/4, and the radicals cancel in the sum: (38 + 38)/4 = 19. Correct.
Answer: 19.

**Trap.** Writing p^2 + q^2 = (p + q)^2 and answering 25 forgets the cross term 2pq entirely. Subtracting pq once instead of twice gives 25 - 3 = 22. Both are silent errors, because neither requires finding the roots and so neither gets caught by a sanity check on the arithmetic.

### Q12 · `ALG-QDR-036` — Answer: 1.5

Step 1 — factor the expression before touching the equation: a^2*b + a*b^2 = ab(a + b).
Step 2 — read off the coefficients: this quadratic has a-coefficient 2, so divide. Sum of roots = -(-6)/2 = 3. Product of roots = 1/2.
Step 3 — multiply: ab(a + b) = (1/2)(3) = 3/2 = 1.5.
Check the long way: the roots are (6 +/- sqrt(28))/4 = (3 +/- sqrt(7))/2. Their product is (9 - 7)/4 = 1/2 and their sum is 3, so the answer is (1/2)(3) = 1.5. Correct.
Answer: 1.5.

**Trap.** Reading the product of the roots as c = 1 rather than c/a = 1/2 gives 1 * 3 = 3. The other common slip is forgetting to divide the sum by a as well and using 6, which gives (1/2)(6) = 3 by a different route. Both land on 3, so getting 3 does not tell you which of the two divisions by a you skipped - the safe habit is to write the a-coefficient down and divide both Vieta quantities by it before multiplying.

### Q13 · `ALG-QDR-028` — Answer: A, B, C

Call the roots r and s, both negative integers. Vieta gives r + s = -b and rs = c.
A — r and s are both negative, so r + s < 0, so -b < 0 and b > 0. TRUE.
B — the product of two negatives is positive, so c = rs > 0. TRUE.
C — the roots are real (they are integers), so the discriminant cannot be negative: b^2 - 4c >= 0. TRUE.
D — FALSE. Take r = s = -1: then b = 2, c = 1 and b^2 - 4c = 4 - 4 = 0. The stem allows the two roots to be equal, so the discriminant can be exactly 0.
E — FALSE. Take r = -1 and s = -2: then b = 3 and c = 2, so c < b. (With r = -2 and s = -3 you get b = 5, c = 6 and c > b, so the comparison is not fixed either way.)
