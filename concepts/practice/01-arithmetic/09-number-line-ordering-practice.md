## Part C — Worked Solutions

### Q1 · `ARI-NLO-001` — Answer: B

Step 1 — place each number. Everything negative sits left of 0; everything positive sits right of 0.
Step 2 — order the negatives. Among negatives, the one further from zero is further LEFT, so it is smaller: -7 < -3.
Step 3 — assemble left to right: -7, -3, 0, 1, 4.
Check: each number is greater than the one before it. -7 < -3 < 0 < 1 < 4. Correct.
Answer: B.

**Trap.** Writing -3 before -7 because 3 < 7 - that ranks the absolute values, not the numbers, and produces choice A. Choice C is the same list read greatest to least, and choice D orders the negatives correctly but then puts 1 before 0.

### Q2 · `ARI-NLO-005` — Answer: 8

Step 1 — distance between a and b is |a - b|, and the order does not matter.
Step 2 — |-6 - 2| = |-8| = 8.
Check by counting: -6 up to 0 is 6 units, 0 up to 2 is 2 more units, total 6 + 2 = 8. Correct.
Answer: 8.

**Trap.** Reporting -8, the raw value of -6 - 2, and forgetting that distance is an absolute value and can never be negative. The other slip is 2 - 6 = -4, which drops the minus sign inside -(-6) and loses the 4 units left of zero.

### Q3 · `ARI-NLO-006` — Answer: D

Step 1 — convert the two endpoints to decimals: -1/2 = -0.50 and 1/4 = 0.25. We need a value x with -0.50 < x < 0.25.
Step 2 — test each choice.
A. -3/4 = -0.75, which is left of -0.50. Out.
B. -1 = -1.00, further left still. Out.
C. 1/2 = 0.50, which is right of 0.25. Out.
D. -1/4 = -0.25. Is -0.50 < -0.25 < 0.25? Yes. In.
E. 3/4 = 0.75, right of 0.25. Out.
Answer: D.

**Trap.** Rejecting -1/4 because -1/4 'looks bigger' than -1/2 in the wrong direction, and taking -3/4 instead. Comparing 1/4 with 1/2 gives 1/4 < 1/2, but attaching the minus sign flips it: -1/4 > -1/2. Among negatives, the fraction closer to zero is the greater one.

### Q4 · `ARI-NLO-007` — Answer: C

Step 1 — Column A: |-5 - 3| = |-8| = 8.
Step 2 — Column B: |2 - (-6)| = |2 + 6| = 8.
Step 3 — 8 = 8, so the two quantities are equal.
Check by counting Column B: from -6 to 0 is 6 units, from 0 to 2 is 2 units, total 8. Correct.
Answer: C.

**Trap.** In Column B, reading 2 - (-6) as 2 - 6 = -4 and taking the distance as 4, which makes Column A look greater and points at choice A. Subtracting a negative adds; the two points are on opposite sides of zero, so their distance is the sum of the two gaps, not the difference.

### Q5 · `ARI-NLO-010` — Answer: -2

Step 1 — the midpoint is the AVERAGE of the two coordinates: (A + B)/2.
Step 2 — keep the signs: (-8 + 4)/2 = (-4)/2 = -2.
Check: distance from -8 to -2 is |-8 - (-2)| = 6, and distance from -2 to 4 is |4 - (-2)| = 6. Equal, so -2 really is the midpoint. Correct.
Answer: -2.

**Trap.** Averaging the absolute values, (8 + 4)/2 = 6, or subtracting instead of adding, (-8 - 4)/2 = -6. The midpoint is an average, never a difference, and the signed coordinates must go in exactly as they stand.

### Q6 · `ARI-NLO-011` — Answer: A

Step 1 — put everything in one form. Decimals to three places:
-3/4 = -0.750
0.7 = 0.700
-0.8 = -0.800
-5/8 = -0.625
sqrt(0.5) is the only one that needs work.
Step 2 — compare sqrt(0.5) with 0.7 by squaring both (both are positive, so squaring preserves order): 0.7^2 = 0.49 and sqrt(0.5)^2 = 0.5. Since 0.49 < 0.50, we get 0.7 < sqrt(0.5).
Step 3 — order the three negatives. The most negative is the smallest: -0.800 < -0.750 < -0.625.
Step 4 — assemble: -0.8 < -3/4 < -5/8 < 0.7 < sqrt(0.5).
Check: sqrt(0.5) = 0.7071, so the last two are 0.700 < 0.707. Correct.
Answer: A.

**Trap.** Choice E is the big one: 5/8 = 0.625 is less than 3/4 = 0.750, so students carry that over and write -5/8 before -3/4. Negating reverses the order, so -5/8 is the GREATER of the two. Choice C comes from applying 'square roots shrink a number' to 0.5 and guessing sqrt(0.5) < 0.7 - true for x > 1, false for 0 < x < 1. Choice D compares 0.75 with 0.8 as if both were positive, and B is the whole list read greatest to least.

### Q7 · `ARI-NLO-012` — Answer: B

Step 1 — locate each column relative to zero. x is negative, so Column A < 0. A square of a non-zero number is positive, so Column B > 0.
Step 2 — anything negative is left of anything positive on the number line, so x < x^2 for EVERY negative x.
Step 3 — sample all of the negative territory to be sure:
x = -5: Column A = -5, Column B = 25. B greater.
x = -1: Column A = -1, Column B = 1. B greater.
x = -0.5: Column A = -0.5, Column B = 0.25. B greater.
x = -0.001: Column A = -0.001, Column B = 0.000001. B greater.
Column B is greater in every case.
Answer: B.

**Trap.** Choosing D because squaring behaves differently on x < -1 (it enlarges the magnitude) than on -1 < x < 0 (it shrinks it). That difference is real but irrelevant here: whatever the magnitude does, the sign flips to positive, and a positive always beats a negative. Never key D just because the magnitudes vary - check whether the ORDER varies.

### Q8 · `ARI-NLO-019` — Answer: A

Step 1 — read |n - 3| as a distance: n is less than 4 units away from 3 on the number line.
Step 2 — that is the open interval centred at 3 with radius 4: 3 - 4 < n < 3 + 4, i.e. -1 < n < 7.
Step 3 — the inequality is strict, so the endpoints -1 and 7 are excluded. The integers strictly inside are 0, 1, 2, 3, 4, 5, 6 - seven of them.
Check the boundary cases: n = -1 gives |-1 - 3| = 4, not less than 4, so -1 is out; n = 7 gives |7 - 3| = 4, also out; n = 6 gives |6 - 3| = 3 < 4, in. Correct.
Answer: A.

**Trap.** Choice D keeps both endpoints, treating '<' as '<='. Choice E is the mirror mistake made only on the left: including -1 but stopping at 5. Choice B includes -1 while correctly excluding 7. Translate the absolute value into a centre and a radius, then decide the endpoints once from the strictness of the sign.

### Q9 · `ARI-NLO-020` — Answer: A, C, E

Test both conditions on each pair.
A - a = -5, b = 3: is -5 < 3? Yes. Is |-5| = 5 > |3| = 3? Yes. TRUE.
B - a = 2, b = 7: is 2 < 7? Yes. Is |2| = 2 > |7| = 7? No. FALSE.
C - a = -4, b = -1: is -4 < -1? Yes. Is 4 > 1? Yes. TRUE.
D - a = -3, b = -5: is -3 < -5? No, -3 is to the RIGHT of -5. FALSE on the first condition already.
E - a = -6, b = -2: is -6 < -2? Yes. Is 6 > 2? Yes. TRUE.
Answer: A, C, E.
The pattern: once a is negative, a larger absolute value pushes it further left, so the two conditions reinforce each other rather than conflict.

**Trap.** Believing |a| > |b| forces a > b and therefore rejecting A, C and E while accepting D. Absolute value measures distance from zero, not position: -6 is six units from zero AND the smaller number. B is the check in the other direction - the ordering holds but the magnitude condition fails, because both numbers are positive there.

### Q10 · `ARI-NLO-021` — Answer: D

Step 1 — write the midpoint condition: (A + C)/2 = B.
Step 2 — substitute: (-6 + C)/2 = 2.
Step 3 — multiply by 2: -6 + C = 4, so C = 10.
Faster route: B must be the same distance from A as from C. A to B is 2 - (-6) = 8 units, so C sits 8 units on the far side of B: C = 2 + 8 = 10.
Check: (-6 + 10)/2 = 4/2 = 2 = B. Correct.
Answer: D.

**Trap.** Choice C, 8, is the DISTANCE from A to B mistaken for the coordinate of C - a length reported where a position was asked. Choice B, -2, is the midpoint of A and B, found by averaging the two given points instead of solving for the far endpoint. Choice A, -14, steps the 8 units from A in the wrong direction (-6 - 8), and choice E, 12, measures the 8 units from 4 instead of from B = 2.

### Q11 · `ARI-NLO-022` — Answer: 7

Step 1 — x - y grows when x grows and when y SHRINKS, because y enters with a minus sign.
Step 2 — take x at its right endpoint, x = 5, and y at its LEFT endpoint, y = -2.
Step 3 — x - y = 5 - (-2) = 5 + 2 = 7.
Check the other three corners: 5 - 4 = 1, -3 - (-2) = -1, -3 - 4 = -7. The largest is 7. Correct.
Answer: 7.

**Trap.** Maximising both variables and answering 5 - 4 = 1. Subtracting a number is the same as adding its opposite, so the most negative allowed y contributes the most. Only the four endpoint combinations can ever be extreme, so if you are unsure, test all four.

### Q12 · `ARI-NLO-023` — Answer: A

Step 1 — write Column B in terms of Column A: x^3 = x^2 times x.
Step 2 — on the interval 0 < x < 1, multiplying a positive number by x SHRINKS it, because the multiplier is between 0 and 1. So x^3 < x^2.
Step 3 — test across the whole interval, including the ends:
x = 0.9: Column A = 0.81, Column B = 0.729. A greater.
x = 0.5: Column A = 0.25, Column B = 0.125. A greater.
x = 0.1: Column A = 0.01, Column B = 0.001. A greater.
Column A is greater everywhere in the interval.
Answer: A.

**Trap.** Applying 'a higher power is a bigger number' and choosing B. That rule holds only for x > 1. For 0 < x < 1 each extra factor of x drags the value further LEFT toward zero, so the powers run x > x^2 > x^3 > ... The stem pins x inside (0, 1), so the relationship never flips and D is wrong.

### Q13 · `ARI-NLO-026` — Answer: A, B, C

Step 1 — find the tipping point. The midpoint of -2 and 4 is (-2 + 4)/2 = 1. Every point left of 1 is closer to -2; every point right of 1 is closer to 4; the point 1 itself is equidistant.
Step 2 — check each option against x < 1 and confirm with the two distances.
A - x = -5: distance to -2 is 3, to 4 is 9. Closer to -2. TRUE.
B - x = -1: distance to -2 is 1, to 4 is 5. Closer to -2. TRUE.
C - x = 0: distance to -2 is 2, to 4 is 4. Closer to -2. TRUE.
D - x = 1: distance to -2 is 3, to 4 is 3. Equidistant, not strictly closer. FALSE.
E - x = 3: distance to -2 is 5, to 4 is 1. Closer to 4. FALSE.
Answer: A, B, C.

**Trap.** Including D. The word 'strictly' rules out the midpoint, which is exactly 3 units from each end - the one point that belongs to neither side. The other error is judging by which number 'looks nearer' rather than computing the midpoint: 0 is closer to -2 even though 0 is a positive-looking value sitting nearer the 4 end of the printed list.

### Q14 · `ARI-NLO-027` — Answer: A

Step 1 — translate the condition. x < y < 0 puts both numbers left of zero with x further left, so |x| > |y|.
Step 2 — squaring depends only on magnitude: x^2 = |x|^2 and y^2 = |y|^2. Since |x| > |y| > 0, squaring preserves that: x^2 > y^2.
Step 3 — therefore x^2 - y^2 > 0 = Column B.
Factored view: x^2 - y^2 = (x - y)(x + y). Here x - y < 0 (x is left of y) and x + y < 0 (both negative), and a negative times a negative is positive. Same conclusion.
Check two very different pairs. x = -4, y = -2: 16 - 4 = 12 > 0. x = -0.5, y = -0.1: 0.25 - 0.01 = 0.24 > 0. Both give A.
Answer: A.

**Trap.** Carrying x < y straight through the squaring to conclude x^2 < y^2 and choosing B. Squaring only preserves order for non-negative numbers; on the negatives it REVERSES order, so the smaller number has the larger square. The stem pins both variables below zero, so the direction never changes and D is wrong.

### Q15 · `ARI-NLO-028` — Answer: E

Step 1 — unpack |a| < b. Since a is negative, |a| = -a, so the condition says -a < b, i.e. b is further from zero than a is.
I - add a to both sides of -a < b: 0 < a + b. So a + b > 0. TRUE.
II - a is negative and b is positive, and neither is zero, so their product is negative. TRUE.
III - start from -a < b and rearrange to a > -b. Divide both sides by b, which is POSITIVE so the inequality direction is unchanged: a/b > -1. TRUE.
All three hold, so the answer is E.
Check with a = -2, b = 5: a + b = 3 > 0, ab = -10 < 0, a/b = -0.4 > -1. All three confirmed.
Answer: E.

**Trap.** Stopping at choice C after verifying the two easy statements and treating III as unknowable. III is exactly statement I divided by the positive number b, so it carries no new risk. The reverse error is worrying that a/b might equal -1: that needs |a| = b, and the stem makes the inequality strict.

### Q16 · `ARI-NLO-029` — Answer: -2

Step 1 — total length: AB = 7 - (-5) = 12.
Step 2 — the ratio 1 : 3 splits AB into 1 + 3 = 4 equal parts, so AC is 1/4 of the whole, not 1/3.
AC = (1/4)(12) = 3.
Step 3 — walk 3 units to the RIGHT from A, since B is to the right: C = -5 + 3 = -2.
