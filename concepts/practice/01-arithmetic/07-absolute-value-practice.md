## Part C — Worked Solutions

### Q1 · `NUM-ABS-003` — Answer: C

Step 1 — read the bars as distance. |x| = 9 says x sits 9 units from 0 on the number line.
Step 2 — there are exactly two such points, one on each side of 0: 9 and -9.
Step 3 — check both: |9| = 9 and |-9| = 9. Both work.
Answer: x = 9 or x = -9.

**Trap.** Answering 'x = 9 only' (choice A). For any k > 0, |x| = k has TWO solutions, and dropping the negative one is the single most common absolute-value error. Choice D, x = 3 or x = -3, comes from confusing the bars with a square and taking sqrt(9) = 3.

### Q2 · `NUM-ABS-004` — Answer: 5

Step 1 — evaluate inside the bars first: 3 - 8 = -5.
Step 2 — take the absolute value: |-5| = 5.
Distance reading: |3 - 8| is the distance between 3 and 8 on the number line, which is 5 whichever way you travel.
Answer: 5.

**Trap.** Splitting the bars as |3| - |8| = 3 - 8 = -5 and entering -5. Absolute value does not distribute over addition or subtraction, and a distance can never come out negative - the sign is the tell that the bars were dropped too early.

### Q3 · `NUM-ABS-006` — Answer: D

Step 1 — the distance between two points a and b on the number line is |a - b|.
Step 2 — |(-4) - 7| = |-11| = 11.
Step 3 — the other order gives the same answer: |7 - (-4)| = |7 + 4| = |11| = 11. That is the whole point of the bars - distance does not care which end you start from.
Answer: 11.

**Trap.** Computing 7 - (-4) as 7 - 4 = 3 (choice B), losing the double negative. Walk it instead: 4 units from -4 up to 0, then 7 more up to 7, so 4 + 7 = 11. Choice A, -11, is the correct subtraction with the bars simply never applied; choice C is |-4|, the distance of the left point from 0 rather than from 7.

### Q4 · `NUM-ABS-008` — Answer: D

Break each claim with a single well-chosen value.
A - take x = -3: |-3| = 3, not -3. FALSE.
B - take x = 3: |3| = 3, not -3. FALSE. (|x| = -x holds only when x <= 0.)
C - take x = 0: |0| = 0, which is not greater than 0. FALSE.
D - |x| is a distance from 0, and a distance is never negative, so |x| >= 0 for every real x, with equality only at x = 0. TRUE.
E - take x = 5: |5| = 5, which is not greater than 5. FALSE.
Answer: D.

**Trap.** Choosing C. |x| > 0 fails at exactly one value, x = 0, where |0| = 0. On 'always true' questions, break the claim with the edge cases first - zero, then a negative. Choice B tempts anyone who has memorised '|x| = -x' without the attached condition x <= 0.

### Q5 · `NUM-ABS-010` — Answer: D

Test one positive and one negative value - those are the only two cases the bars distinguish.
Case x = 4: Column A = |4| = 4, Column B = 4. The columns are equal.
Case x = -4: Column A = |-4| = 4, Column B = -4. Column A is greater.
One case points to C and the other to A, so no single relationship holds for all allowed x.
Answer: D.

**Trap.** Choosing A because 'absolute value makes a number bigger'. It does not: for every positive x, |x| = x exactly, and the columns tie. The mirror error is choosing C after testing only x = 4. Whenever a variable inside bars is unrestricted in sign, test a negative before you answer.

### Q6 · `NUM-ABS-013` — Answer: D

Greater-than splits into two rays joined by OR, not one interval.
Case 1 — 2x + 1 > 5: 2x > 4, so x > 2.
Case 2 — 2x + 1 < -5 (the inside is far to the LEFT of zero, so the sign reverses): 2x < -6, so x < -3.
Solution: x < -3 or x > 2.
Check the boundaries: at x = 2, |2(2) + 1| = |5| = 5, which is not greater than 5, so 2 is correctly excluded; at x = 3, |7| = 7 > 5. Correct.
Answer: x < -3 or x > 2.

**Trap.** Choice A is the solution set of |2x + 1| < 5 - the classic flip. Less-than keeps you INSIDE one interval (AND); greater-than throws you OUTSIDE onto two rays (OR). Choices B and C each come from solving one case and forgetting the other. Choice E comes from dropping the +1 and treating the inequality as |2x| > 5.

### Q7 · `NUM-ABS-014` — Answer: -33

Step 1 — read it as distance: x + 4 sits 7 units from 0, so x + 4 = 7 or x + 4 = -7.
Step 2 — Case 1: x + 4 = 7 gives x = 3.
Step 3 — Case 2: x + 4 = -7 gives x = -11.
Step 4 — the product: 3 x (-11) = -33.
Check: |3 + 4| = |7| = 7 and |-11 + 4| = |-7| = 7. Both are genuine solutions. Correct.
Answer: -33.

**Trap.** Two live errors. Solving only the positive case leaves x = 3 alone and a 'product' of 3. Reading 'product' as 'sum' gives 3 + (-11) = -8. The two roots of |x + c| = k are symmetric about -c, not about 0, so they are almost never equal in size.

### Q8 · `NUM-ABS-015` — Answer: C

Step 1 — since a < 0 and b < 0, the sum a + b is negative too.
Step 2 — for a negative quantity n, |n| = -n. So Column A = -(a + b) = -a - b.
Step 3 — likewise |a| = -a and |b| = -b, so Column B = -a - b.
The two columns are the same expression, so they are equal for every pair of negative a and b.
Check with numbers: a = -3, b = -5. Column A = |-8| = 8; Column B = 3 + 5 = 8. Equal.
Answer: C.

**Trap.** Choosing B because the triangle inequality |a + b| <= |a| + |b| is remembered as strict. It is strict only when a and b have OPPOSITE signs, where partial cancellation shrinks the left side. With the same sign there is nothing to cancel and the two sides match exactly. Choosing D because a and b are unnamed is the other error - the stem pins both signs, which is all the equality needs.

### Q9 · `NUM-ABS-016` — Answer: B, C, D

Step 1 — distance reading: x lies within 3 units of 1.
Step 2 — that is the interval from 1 - 3 to 1 + 3 with the endpoints included: -2 <= x <= 4.
A - x = -3: |-3 - 1| = |-4| = 4, and 4 is not <= 3. FALSE.
B - x = -2: |-2 - 1| = |-3| = 3, and 3 <= 3. TRUE (endpoint counts).
C - x = 0: |0 - 1| = 1 <= 3. TRUE.
D - x = 4: |4 - 1| = 3 <= 3. TRUE (endpoint counts).
E - x = 5: |5 - 1| = 4, not <= 3. FALSE.
Answer: B, C, D.

**Trap.** Forgetting to shift by the centre and solving |x - 1| <= 3 as -3 <= x <= 3. That admits A (-3) and rejects D (4) - exactly the two options that flip. The centre is 1, not 0. The second slip is throwing out B and D on the belief that the bars force a strict inequality; the <= sign keeps both endpoints.

### Q10 · `NUM-ABS-017` — Answer: D

|n| = n exactly when n >= 0, so the columns tie whenever x^2 - 4 >= 0 and separate whenever x^2 - 4 < 0.
Case x = 3: x^2 - 4 = 5, positive. Column A = |5| = 5, Column B = 5. Equal.
Case x = 1: x^2 - 4 = -3, negative. Column A = |-3| = 3, Column B = -3. Column A is greater.
Both x = 3 and x = 1 obey the stem's x > 0, so two different relationships are possible.
Answer: D.

**Trap.** Assuming x > 0 forces x^2 > 4 and answering C. It does not - every x strictly between 0 and 2 has x^2 < 4, making the inside of the bars negative. The stem restricts the sign of x, but the sign that decides this comparison is the sign of x^2 - 4.

### Q11 · `NUM-ABS-020` — Answer: C, D

|a| = |b| means a = b or a = -b - two cases, always.
Case 1 — 2x - 4 = x + 1 gives x = 5.
Case 2 — 2x - 4 = -(x + 1) = -x - 1 gives 3x = 3, so x = 1.
Now test every option in the original equation.
A - x = -5: |2(-5) - 4| = |-14| = 14, but |-5 + 1| = |-4| = 4. FALSE.
B - x = -1: |2(-1) - 4| = |-6| = 6, but |-1 + 1| = 0. FALSE.
C - x = 1: |2 - 4| = 2 and |1 + 1| = 2. TRUE.
D - x = 5: |10 - 4| = 6 and |5 + 1| = 6. TRUE.
E - x = 7: |14 - 4| = 10, but |7 + 1| = 8. FALSE.
Answer: C, D.

**Trap.** Setting up only 2x - 4 = x + 1, finding x = 5 and selecting D alone. The second case, obtained by negating exactly ONE side, is where x = 1 lives. The related slip is negating both sides at once: -(2x - 4) = -(x + 1) is Case 1 multiplied through by -1 and produces nothing new.

### Q12 · `NUM-ABS-023` — Answer: 7

Step 1 — distance reading: x is strictly within 4 units of 2.
Step 2 — that is the open interval 2 - 4 < x < 2 + 4, i.e. -2 < x < 6.
Step 3 — count the integers strictly inside: -1, 0, 1, 2, 3, 4, 5. That is 7 values.
Check the ends: x = -2 gives |-4| = 4, not < 4, so -2 is out; x = 6 gives |4| = 4, also out. Correct.
Answer: 7.

**Trap.** Counting the endpoints -2 and 6 as well and answering 9. The inequality is strict, so both ends fail by exactly nothing. The other error is answering 8 by reporting the WIDTH of the interval, 6 - (-2) = 8, instead of the number of integers it contains.

### Q13 · `NUM-ABS-025` — Answer: C

Distance reading first: |x - (-2)| = |x - 6| says x is the same distance from -2 as from 6, so x is the midpoint.
Midpoint = (-2 + 6)/2 = 4/2 = 2.
Algebraic confirmation - two cases:
Case 1 — x + 2 = x - 6 gives 2 = -6, impossible, so this case contributes no solution.
Case 2 — x + 2 = -(x - 6) = -x + 6 gives 2x = 4, so x = 2.
Check: |2 + 2| = 4 and |2 - 6| = |-4| = 4. Equal. Correct.
Answer: 2.

**Trap.** Dropping the bracket when negating: writing x + 2 = -x - 6 instead of x + 2 = -(x - 6) = -x + 6, which gives 2x = -8 and x = -4, choice A. Choice D, 4, comes from reading the two centres straight off the signs as printed, 2 and 6, and taking their midpoint (2 + 6)/2 = 4 - but the centre of |x + 2| is -2, not 2; choices B and E are the two true centres themselves, for anyone who reads the equation as 'x is one of those numbers'. A third slip is to hit 2 = -6 in Case 1 and stop there: one dead case is normal for |a| = |b| when the x terms match, and the solution lives in the other case.

### Q14 · `NUM-ABS-027` — Answer: C

Peel the outer bars first. Let u = |x|.
Step 1 — |u - 3| = 2 gives u - 3 = 2 or u - 3 = -2, so u = 5 or u = 1.
Step 2 — now peel the inner bars. Each value of u is itself an absolute value, so each one splits again:
|x| = 5 gives x = 5 or x = -5.
|x| = 1 gives x = 1 or x = -1.
Step 3 — the solution set is {-5, -1, 1, 5}, which is 4 integers.
Check one from each branch: ||5| - 3| = |2| = 2 and ||-1| - 3| = |-2| = 2. Correct.
Answer: 4.

**Trap.** Stopping after Step 1 and answering 2, having counted two values of |x| rather than two values of x. Nested bars double the count at each level: 2 outer cases x 2 inner cases = 4. Answering 3 comes from remembering the negative branch for only one of u = 5 and u = 1.

### Q15 · `NUM-ABS-028` — Answer: 4

The critical points, where each expression inside the bars changes sign, are x = 3 and x = -1. Split the number line into three regions.
Region 1 (x < -1) — both insides are negative:
-(x - 3) - (x + 1) = -x + 3 - x - 1 = -2x + 2 = 6, so -2x = 4 and x = -2. Since -2 < -1, this solution belongs to its region. Valid.
Region 2 (-1 <= x <= 3) — the first inside is negative, the second positive:
-(x - 3) + (x + 1) = -x + 3 + x + 1 = 4. That is the constant 4, never 6, so no solutions here.
Region 3 (x > 3) — both insides are positive:
(x - 3) + (x + 1) = 2x - 2 = 6, so 2x = 8 and x = 4. Since 4 > 3, this solution belongs to its region. Valid.
The complete solution set is {-2, 4}, so the greatest value is 4.
Check: |4 - 3| + |4 + 1| = 1 + 5 = 6. Correct.
Answer: 4.

**Trap.** Dropping both sets of bars and solving (x - 3) + (x + 1) = 6 straight through. That happens to land on 4 here, but the same shortcut applied on the left of -1 loses x = -2 entirely, and a question asking for the LEAST value would be answered wrongly. The structural point is Region 2: between the critical points the expression is frozen at 4, which is the minimum of |x - 3| + |x + 1| and equals the distance from -1 to 3.

### Q16 · `NUM-ABS-029` — Answer: E

Step 1 — factor: a^2 - b^2 = (a + b)(a - b).
Step 2 — the bars fix only the sizes, not the signs. |a + b| = 3 means a + b = 3 or a + b = -3; |a - b| = 5 means a - b = 5 or a - b = -5.
Step 3 — the sign combinations really are available:
a + b = 3 and a - b = 5 give a = 4, b = -1, so a^2 - b^2 = 16 - 1 = 15.
a + b = 3 and a - b = -5 give a = -1, b = 4, so a^2 - b^2 = 1 - 16 = -15.
Step 4 — the product is +15 or -15 depending on the signs, and nothing in the stem pins them down.
Answer: it cannot be determined.

**Trap.** Computing |a + b| x |a - b| = 3 x 5 = 15 and choosing C. That correctly gives |a^2 - b^2| = 15 - the SIZE of the answer - but the sign is exactly what the bars discarded. Choice D, 16, comes from squaring the two given numbers and subtracting, 25 - 9, as if |a - b| were a and |a + b| were b.

### Q17 · `NUM-ABS-030` — Answer: C

For any nonzero n, |n|/n equals +1 when n > 0 and -1 when n < 0 - it is nothing but the sign of n.
So Column B is (sign of x) x (sign of y), and Column A is the sign of the product xy.
Algebraically: |xy| = |x| x |y| (absolute value does distribute over multiplication), so Column A = (|x| x |y|)/(xy) = (|x|/x)(|y|/y) = Column B.
Check all four sign cases:
x > 0, y > 0: xy > 0, so A = 1; B = (1)(1) = 1. Equal.
x > 0, y < 0: xy < 0, so A = -1; B = (1)(-1) = -1. Equal.
x < 0, y > 0: xy < 0, so A = -1; B = (-1)(1) = -1. Equal.
x < 0, y < 0: xy > 0, so A = 1; B = (-1)(-1) = 1. Equal.
Answer: C.

**Trap.** Choosing D because two variables of unknown sign look like four uncontrolled outcomes. They are not uncontrolled: |ab| = |a| x |b| forces the sign of a product to equal the product of the signs, so the two columns are one expression written two ways. Testing only x > 0, y > 0 and then only x < 0, y < 0 - both of which return 1 = 1 - and then hedging is how students talk themselves into D.
