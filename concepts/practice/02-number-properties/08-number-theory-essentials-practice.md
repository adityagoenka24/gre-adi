## Part C — Worked Solutions

### Q1 · `NUM-NTH-001` — Answer: C

Step 1 — a number is rational when it can be written as a/b with a and b integers and b not 0.
Step 2 — test each option.
A - 0 = 0/1. Rational.
B - -7/4 is already a ratio of integers. Rational.
C - 10 is not a perfect square (3^2 = 9, 4^2 = 16), so sqrt(10) = 3.1622... never terminates and never repeats. Irrational.
D - 0.666... repeats, and a repeating decimal is always rational: 0.666... = 2/3.
E - 3.25 terminates, so 3.25 = 325/100 = 13/4. Rational.
Check: only C fails to be a ratio of two integers.
Answer: C.

**Trap.** Choosing D because 0.666... never ends. Non-terminating is not the same as irrational - irrational means non-terminating AND non-repeating. A repeating block always converts to a fraction (0.666... = 2/3), which is why D is rational and C is not.

### Q2 · `NUM-NTH-003` — Answer: B

Step 1 — work from the definition, not from a remembered slogan. 'd is a factor of N' means N = d x m for some integer m.
Step 2 — put d = 0. The condition becomes k = 0 x m, and 0 x m = 0 for every integer m. So k must be 0, and 0 does qualify: 0 = 0 x 1. TRUE.
Step 3 — test A. k = 1 would need 1 = 0 x m, and no integer m gives 1. FALSE.
Step 4 — test C. This swaps the two words. 0 = n x 0 says 0 is a MULTIPLE of every integer; it says nothing about 0 being a factor. FALSE.
Step 5 — test D. The evenness of 0 is irrelevant here: k = 4 would need 4 = 0 x m, which has no solution. FALSE.
Step 6 — test E. Its reason is right for every non-zero k, but it overreaches. 0 is a factor of no NON-ZERO integer, yet 0 = 0 x 1 makes 0 a factor of 0. So exactly one integer k works, rather than none. FALSE.
Check: 0 x m runs through the single value 0 as m runs through the integers, so the set of integers having 0 as a factor is exactly {0}. Correct.
Answer: B.

**Trap.** Choosing E by quoting 'zero is a factor of nothing' as an absolute. The true form is that 0 is a factor of no non-zero integer, and k = 0 itself survives, since 0 = 0 x 1. Choosing C by reading the sentence backwards: 0 is a multiple of every integer, which is the reverse of what the stem states.

### Q4 · `NUM-NTH-005` — Answer: B

Step 1 — test each statement against the three dangerous inputs: a negative, zero, and one.
A - n = 0 gives n^2 = 0, which is not greater than 0. FALSE.
B - a square is a product of two equal numbers, so it is positive when n is not 0 and equals 0 when n = 0. Never negative. TRUE.
C - n = 1 gives n^2 = 1 = n, not greater. n = 0 gives 0 = 0. FALSE.
D - n = 2 gives n^2 = 4, even. FALSE.
E - n = -2 gives n^3 = -8 < 0. A cube keeps the sign of its base. FALSE.
Check: B survives n = -3 (9 >= 0), n = 0 (0 >= 0) and n = 5 (25 >= 0).
Answer: B.

**Trap.** Picking A by forgetting that n = 0 is an integer, so n^2 can equal 0 rather than exceed it. Picking C assumes squaring always enlarges, which fails at n = 0 and n = 1 (and for every number strictly between 0 and 1).

### Q5 · `NUM-NTH-006` — Answer: 42

Step 1 — a repeating decimal is rational. A repeating block of three digits converts directly by writing the block over 999: 0.135135135... = 135/999.
Step 2 — factor both parts. 135 = 3^3 x 5 and 999 = 3^3 x 37, so the common factor is 27.
Step 3 — divide both by 27: 135/999 = 5/37.
Step 4 — 5 and 37 are both prime and unequal, so the fraction is in lowest terms and a + b = 5 + 37 = 42.
Check: 5/37 = 0.135135135..., and 5 and 37 share no factor greater than 1. Correct.
Answer: 42.

**Trap.** Answering 1,134 by using the unreduced fraction 135/999 (135 + 999 = 1,134). The stem demands lowest terms, so the common factor 27 must be cancelled first. Answering 227 comes from writing the block over 1,000 instead of 999: 135/1,000 reduces to 27/200, giving 27 + 200 = 227, but 0.135 is not the same number as 0.135135135...

### Q6 · `NUM-NTH-011` — Answer: D

Step 1 — irrational means the decimal never terminates and never repeats; equivalently, the number is not a ratio of two integers.
Step 2 — test each option.
A - the block 47 repeats, so 0.474747... = 47/99. Rational.
B - 49 = 7^2, so sqrt(49) = 7, an integer. Rational.
C - 22/7 is a ratio of integers by construction. Rational. (It is a famous approximation of pi, but it is not pi.)
D - 45 = 3^2 x 5, so sqrt(45) = 3 x sqrt(5). Since 5 is not a perfect square, sqrt(5) is irrational, and a non-zero rational (3) times an irrational is irrational. Irrational.
E - -3/8 = -0.375, terminating. Rational.
Check: the square root of a positive integer is rational only when that integer is a perfect square. 49 is; 45 is not.
Answer: D.

**Trap.** Choosing C because 22/7 is used as a stand-in for pi. A fraction of two integers is rational no matter what it approximates. Choosing A because the decimal never stops - repeating decimals are always rational.

### Q8 · `NUM-NTH-013` — Answer: 6

Step 1 — the units digit of n^2 depends only on the units digit of n, because every other digit of n feeds only the tens column and higher.
Step 2 — square each possible units digit: 0->0, 1->1, 2->4, 3->9, 4->6, 5->5, 6->6, 7->9, 8->4, 9->1.
Step 3 — units digit 4 comes only from n ending in 2 or in 8.
Step 4 — list those n below 30: 2, 8, 12, 18, 22, 28. That is 6 values.

### Q9 · `NUM-NTH-014` — Answer: B, E

The statements differ on NEGATIVE integers, so a negative test value does the work here; zero settles nothing.
A - n = -2 gives n^3 = -8 and n = -2, and -8 >= -2 is false. A cube keeps the sign of its base and pushes a negative further from 0. FALSE.
B - n^2 - n = n(n - 1), a product of two consecutive integers. Consecutive integers are never one positive and one negative at the same time with a gap between them: either both are >= 0 or both are <= 0, so the product is >= 0. Check n = -3 (9 >= -3), n = 0 (0 >= 0), n = 1 (1 >= 1), n = 4 (16 >= 4). TRUE.
C - n = -1 gives n^3 = -1 and n^2 = 1, and -1 >= 1 is false. A cube can be negative while the square is positive. FALSE.
D - expand: (n + 1)^2 - n^2 = 2n + 1, which is positive only when n >= 0. At n = -1 it is -1, and indeed (n + 1)^2 = 0 while n^2 = 1. FALSE.
E - absolute value strips the sign first: |n^3| = |n|^3, so the claim is |n|^3 >= |n| with |n| a non-negative integer. If |n| = 0 both sides are 0; if |n| >= 1 then multiplying |n| by |n|^2 >= 1 cannot shrink it. Check n = -4 (64 >= 4), n = 0 (0 >= 0), n = 1 (1 >= 1). TRUE.
Answer: B and E.

**Trap.** Accepting A and C by testing only positive n, where cubes do dominate; both die at a single negative (n = -2 for A, n = -1 for C). Accepting D because 'adding 1 before squaring must enlarge it' - squaring is not order-preserving on negatives, and n = -1 turns 1 into 0. Rejecting B on the ground that squaring shrinks numbers between 0 and 1: true for numbers, but no INTEGER lies strictly between 0 and 1.

### Q10 · `NUM-NTH-015` — Answer: E

Step 1 — for a > 1, raising to a higher power increases the value: sqrt(a) < a < a^2.
Step 2 — taking reciprocals of positive numbers reverses order, so 1/a^2 < 1/a < 1/sqrt(a) < 1.
Step 3 — combine: 1/a^2 < 1/a < 1 < sqrt(a) < a < a^2. The smallest is 1/a^2.
Step 4 — confirm with a = 4: a = 4, a^2 = 16, sqrt(a) = 2, 1/a = 0.25, 1/a^2 = 0.0625. The smallest is 0.0625.
Check with a = 1.44: 1/a^2 = 0.482, 1/a = 0.694, sqrt(a) = 1.2, a = 1.44, a^2 = 2.07. Same order.
Answer: E.

**Trap.** Choosing D because 1/a is the only option that obviously looks small, forgetting that squaring a number already between 0 and 1 makes it smaller still. Choosing C by importing the rule for 0 < a < 1, where sqrt(a) is larger than a, not smaller.

### Q11 · `NUM-NTH-017` — Answer: A

Step 1 — suppose sqrt(n) were rational, so sqrt(n) = p/q with p and q integers, q not 0, and the fraction in lowest terms.
Step 2 — square both sides: n = p^2/q^2. Since p/q is in lowest terms, so is p^2/q^2, so for n to be an integer we need q^2 = 1, i.e. q = 1.
Step 3 — then n = p^2, making n a perfect square - contradicting the stem.
Step 4 — so sqrt(n) cannot be rational. It is irrational.
Check: n = 45 is not a square and sqrt(45) = 6.708..., non-terminating and non-repeating. n = 49 IS a square and sqrt(49) = 7. The rule has no exceptions.
Answer: A.

**Trap.** Choosing B because sqrt(45) = 6.708... 'looks like a decimal, so it must be a fraction'. There is no middle ground: the square root of a positive integer is either an integer or irrational, never a non-integer fraction. Choosing E treats the outcome as case-dependent, but the stem has already ruled out the only rational case.

### Q12 · `NUM-NTH-022` — Answer: B, C, E

Two separate steps: first the factor COUNT, from the prime factorisation - if N = p^a x q^b x ..., the count is (a + 1)(b + 1)... - and only then the perfect-square test on that count.
A - 24 = 2^3 x 3^1. Count = (3 + 1)(1 + 1) = 8. 8 is not a perfect square (4 and 9 straddle it). FALSE.
B - 36 = 2^2 x 3^2. Count = 3 x 3 = 9 = 3^2. TRUE.
C - 225 = 3^2 x 5^2. Count = 3 x 3 = 9 = 3^2. TRUE.
D - 512 = 2^9, a single prime power. Count = 9 + 1 = 10. 10 is not a perfect square (9 and 16 straddle it), even though the exponent 9 is. FALSE.
E - 1,000 = 2^3 x 5^3. Count = 4 x 4 = 16 = 4^2. TRUE. Note 1,000 is NOT a perfect square - its exponents are odd, and an odd exponent means an even factor count - yet 16 is a perfect square all the same. The question is about the count, not about N.
Check by the pairing rule: a factor count is odd exactly when N is a perfect square, so 36 and 225 must have odd counts (9 and 9) and 24, 512 and 1,000 must have even counts (8, 10 and 16). That matches, and of the even counts only 16 is itself a square. Correct.
Answer: B, C and E.

**Trap.** Choice D is the exponent trap: reading 512 = 2^9 and calling the exponent 9 the factor count, or simply seeing the square number 9 in the exponent, gives 'perfect square' when the count is 9 + 1 = 10 and the +1 for the exponent 0 is what breaks it. Testing whether the INTEGER is a perfect square instead of whether its factor count is: that keeps 36 and 225, correctly drops 512, but wrongly discards 1,000 = 2^3 x 5^3, whose 16 factors are 4^2. Including A by squaring one bracket instead of multiplying the brackets, reading 24 = 2^3 x 3 as (3 + 1)^2 = 16 factors rather than (3 + 1)(1 + 1) = 8.

### Q14 · `NUM-NTH-027` — Answer: C

Step 1 — factor the form: p^2 - q^2 = (p - q)(p + q). Write the target as a product of two factors f x g with f = p - q and g = p + q.
Step 2 — solving gives p = (f + g)/2 and q = (g - f)/2, so p and q are integers exactly when f and g have the SAME parity (both odd or both even).
Step 3 — an odd target factors as odd x odd, so every odd integer works. An even target needs even x even, so it must be divisible by 4.
