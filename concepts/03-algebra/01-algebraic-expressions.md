# Algebraic Expressions & Simplification

**Section:** Algebra  |  **Bank code:** ALG-EXP  |  **GRE frequency:** Very High

---

## 1. Core Idea

An **expression** has no equals sign — you simplify it. An **equation** has one — you solve it. Simplification means rewriting the same value in a shorter or more useful form.

On the GRE, simplification is rarely the goal in itself: it is the step that makes the real question easy. Most "impossible-looking" algebra questions collapse after one correct expansion or factorisation.

---

## 2. Must-Know Rules

**The identities you must know cold:**

| Identity | |
|---|---|
| (a + b)^2 | a^2 + 2ab + b^2 |
| (a - b)^2 | a^2 - 2ab + b^2 |
| (a + b)(a - b) | a^2 - b^2 |
| (a + b)^3 | a^3 + 3a^2 b + 3ab^2 + b^3 |
| a^3 + b^3 | (a + b)(a^2 - ab + b^2) |
| a^3 - b^3 | (a - b)(a^2 + ab + b^2) |
| (x + a)(x + b) | x^2 + (a+b)x + ab |

**Derived forms the GRE loves:**

- a^2 + b^2 = (a + b)^2 - 2ab
- a^2 + b^2 = (a - b)^2 + 2ab
- (a + b)^2 - (a - b)^2 = 4ab
- If x + 1/x = k, then x^2 + 1/x^2 = k^2 - 2

**Order of operations:** PEMDAS/BODMAS — brackets, exponents, multiply/divide (left to right), add/subtract (left to right).

**Like terms** can be combined; unlike terms cannot. 3x^2 + 5x^2 = 8x^2, but 3x^2 + 5x stays as it is.

**Complex fractions:** multiply numerator and denominator by the LCM of the inner denominators.

## 3. Worked Examples

### Example 1 — Using an identity instead of solving

*If a + b = 9 and ab = 14, find a^2 + b^2.*

a^2 + b^2 = (a + b)^2 - 2ab = 81 - 28 = **53**.

Note you never had to find a and b individually. (They happen to be 2 and 7, but finding them is slower.)

### Example 2 — Difference of squares as a shortcut

*Compute 103^2 - 97^2 without a calculator.*

(103 + 97)(103 - 97) = 200 x 6 = **1,200**.

### Example 3 — Simplifying a complex fraction

*Simplify (1/x - 1/y) / (1/x + 1/y).*

Multiply top and bottom by xy:

Numerator: y - x. Denominator: y + x.

Result = **(y - x)/(y + x)**.

## 4. GRE Traps

- **(a + b)^2 = a^2 + b^2.** The middle term 2ab is missing. This is the single most common algebra error on the test.
- **(a - b)^2 = a^2 - b^2.** No — that is the *factorisation of a difference of squares*, a different identity.
- **Distributing a negative sign partially.** -(x - 3) = -x + 3, not -x - 3.
- **Cancelling across a plus sign.** (x + 3)/3 is not x. You can only cancel common *factors*, never terms.
- **sqrt(a^2 + b^2) = a + b.** False.
- **Dividing by a variable that might be 0.** From x^2 = 3x you cannot just divide by x; you get x^2 - 3x = 0, x(x - 3) = 0, so x = 0 or 3. Dividing loses the x = 0 root.
- **Order of operations with exponents.** 2 x 3^2 = 18, not 36.

---

## 5. Speed Tricks

- **Look for a^2 - b^2 in any numeric subtraction of squares.** It turns big arithmetic into a two-step multiplication.
- **When given a + b and ab, expect an identity question.** You will almost never need a and b separately.
- **Factor before you expand.** GRE answer choices are usually in factored form.
- **For x + 1/x problems, square both sides.** That single move solves nearly all of them.
- **Substitute a number to check an identity** if you are unsure: pick x = 2 and verify both sides.

## 6. Self-Check

**Q1.** Expand (2x - 5)^2.

**Q2.** If x - y = 4 and xy = 12, find x^2 + y^2.

**Q3.** Simplify (x^2 - 9)/(x + 3), for x not equal to -3.

<details>
<summary>Answers</summary>

**A1.** 4x^2 - 20x + 25.

**A2.** x^2 + y^2 = (x - y)^2 + 2xy = 16 + 24 = **40**.

**A3.** (x-3)(x+3)/(x+3) = **x - 3**.

</details>

## 7. One-Line Summary for the Board

> (a+b)^2 has a middle term. You can cancel factors, never terms. Factor before you expand.
