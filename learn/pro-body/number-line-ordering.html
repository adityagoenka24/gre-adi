2. Must-Know Rules

Concept Rule
Ordering Right on the number line = greater
Midpoint of a and b (a + b)/2
Distance between a and b |a - b|
Negatives Closer to zero = greater. -1/2 > -1
Squaring, 0 < x < 1 x^2 < x (moves left, toward 0)
Squaring, x > 1 x^2 > x (moves right)
Square root, 0 < x < 1 sqrt(x) > x
Square root, x > 1 sqrt(x) < x
Reciprocal, x > 1 1/x is between 0 and 1
Reciprocal of a negative still negative

The four regions to test. Whenever a variable is unrestricted, a complete check needs a value from each of:

x < -1, -1 < x < 0, 0 < x < 1, x > 1

plus the boundary cases 0, 1, -1. This "FROZEN" style check (Fractions, Repeats, One, Zero, Extremes, Negatives) is what makes quantitative comparison questions safe.

Mixed-type comparison. Convert everything to decimals to 2-3 places, or find a common denominator. Do not eyeball.

3. Worked Examples

Example 1 — Mixed types

Order from least to greatest: 0.6, 5/8, 62%, sqrt(0.36).

Convert all to decimals:

  • 0.6 = 0.600
  • 5/8 = 0.625
  • 62% = 0.620
  • sqrt(0.36) = 0.6 = 0.600

So: 0.6 = sqrt(0.36) < 62% < 5/8.

Example 2 — Behaviour on an interval

If -1 < x < 0, order x, x^2, x^3 from least to greatest.

Pick x = -0.5.

  • x = -0.5
  • x^2 = 0.25
  • x^3 = -0.125

Order: -0.5 < -0.125 < 0.25, so x < x^3 < x^2.

The insight: odd powers keep the sign, even powers make it positive, and magnitudes shrink because |x| < 1.

Example 3 — Midpoint

Point A is at -7 and point B is at 11 on a number line. What is the coordinate of the midpoint, and how far apart are A and B?

Midpoint = (-7 + 11)/2 = 4/2 = 2.

Distance = |11 - (-7)| = 18.

4. GRE Traps

  • -3 > -2. No. More negative means smaller. -3 < -2.
  • Assuming squaring makes a number bigger. Only true outside (-1, 1). For 0 < x < 1, squaring shrinks it.
  • |a| > |b| implies a > b. False: a = -5, b = 3.
  • Comparing fractions by numerator alone. 3/4 vs 5/8 — must find a common basis.
  • Forgetting zero and one as test cases. They break most "which is greater" patterns.
  • Assuming a variable is positive. Unless the problem says so, it isn't.
  • Midpoint by subtraction. Midpoint is the average, not the difference.

5. Speed Tricks

  • Convert to decimals for mixed lists — 3 decimal places is always enough on the GRE.
  • Benchmark against 1/2 and 1. Fast triage before precise comparison.
  • Draw it. A 10-second sketch of the number line prevents nearly every sign error.
  • For quantitative comparison with variables, test four values: a big positive, a small positive fraction, zero (if allowed), and a negative. If two tests disagree, the answer is D.
  • The distance formula |a - b| is symmetric — order doesn't matter, so take the positive difference.

6. Self-Check

Q1. Order from least to greatest: -0.7, -3/4, -2/3.

Q2. If 0 < x < 1, which is largest: x, x^2, or sqrt(x)?

Q3. What is the midpoint of -12 and 5?

Answers

A1. As decimals: -0.7, -0.75, -0.667. Least is the most negative: -3/4 < -0.7 < -2/3.

A2. sqrt(x) — for a proper fraction, roots grow and powers shrink.

A3. (-12 + 5)/2 = -7/2 = -3.5.

7. One-Line Summary for the Board

Right is greater. For negatives, closer to zero wins. Always test 0, 1, and a negative.
