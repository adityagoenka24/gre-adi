Q1 · NUM-NTH-001 — Answer: D

Step 1 — a number is rational when it can be written as a/b with a and b integers and b not 0. Step 2 — test each option. A - -7/4 is already a ratio of integers. Rational. B - 0 = 0/1. Rational. C - 0.666... repeats, and a repeating decimal is always rational: 0.666... = 2/3. D - 10 is not a perfect square (3^2 = 9, 4^2 = 16), so sqrt(10) = 3.1622... Never terminates and never repeats. Irrational. E - 3.25 terminates, so 3.25 = 325/100 = 13/4. Rational. Check: only D fails to be a ratio of two integers. Answer: D.

Trap. Choosing C because 0.666... Never ends. Non-terminating is not the same as irrational - irrational means non-terminating AND non-repeating. A repeating block always converts to a fraction (0.666... = 2/3), which is why C is rational and D is not.

Q2 · NUM-NTH-003 — Answer: B

Step 1 — work from the definition, not from a remembered slogan. 'd is a factor of N' means N = d x m for some integer m. Step 2 — put d = 0. The condition becomes k = 0 x m, and 0 x m = 0 for every integer m. So k must be 0, and 0 does qualify: 0 = 0 x 1. True. Step 3 — test A. k = 1 would need 1 = 0 x m, and no integer m gives 1. False. Step 4 — test C. This swaps the two words. 0 = n x 0 says 0 is a MULTIPLE of every integer; it says nothing about 0 being a factor. False. Step 5 — test D. The evenness of 0 is irrelevant here: k = 4 would need 4 = 0 x m, which has no solution. False. Step 6 — test E. Its reason is right for every non-zero k, but it overreaches. 0 is a factor of no NON-ZERO integer, yet 0 = 0 x 1 makes 0 a factor of 0. So exactly one integer k works, rather than none. False. Check: 0 x m runs through the single value 0 as m runs through the integers, so the set of integers having 0 as a factor is exactly {0}. Correct. Answer: B.

Trap. Choosing E by quoting 'zero is a factor of nothing' as an absolute. The true form is that 0 is a factor of no non-zero integer, and k = 0 itself survives, since 0 = 0 x 1. Choosing C by reading the sentence backwards: 0 is a multiple of every integer, which is the reverse of what the stem states.

Q9 · NUM-NTH-014 — Answer: B, E

The statements differ on negative integers, so a negative test value does the work here; zero settles nothing. A - n = -2 gives n^3 = -8 and n = -2, and -8 >= -2 is false. A cube keeps the sign of its base and pushes a negative further from 0. False. B - n^2 - n = n(n - 1), a product of two consecutive integers. Consecutive integers are never one positive and one negative at the same time with a gap between them: either both are >= 0 or both are <= 0, so the product is >= 0. Check n = -3 (9 >= -3), n = 0 (0 >= 0), n = 1 (1 >= 1), n = 4 (16 >= 4). True. C - n = -1 gives n^3 = -1 and n^2 = 1, and -1 >= 1 is false. A cube can be negative while the square is positive. False. If |n| = 0 both sides are 0; if |n| >= 1 then multiplying |n| by |n|^2 >= 1 cannot shrink it. Check n = -4 (64 >= 4), n = 0 (0 >= 0), n = 1 (1 >= 1). True. Answer: B and E.

Trap. Accepting A and C by testing only positive n, where cubes do dominate; both die at a single negative (n = -2 for A, n = -1 for C). Q11 · NUM-NTH-017 — Answer: A
