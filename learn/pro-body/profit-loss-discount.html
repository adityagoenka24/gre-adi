2. Must-Know Rules

Concept Formula
Profit SP - CP
Loss CP - SP
Profit % (SP - CP)/CP x 100
Loss % (CP - SP)/CP x 100
SP from profit % SP = CP(1 + p/100)
CP from SP and profit % CP = SP / (1 + p/100)
Discount MP - SP
Discount % (MP - SP)/MP x 100
SP after discount SP = MP(1 - d/100)
Markup % (MP - CP)/CP x 100

The chain. Most multi-step questions run CP -> MP -> SP:

SP = CP x (1 + markup) x (1 - discount)

Successive discounts multiply, they do not add. Two successive 20% discounts give 0.8 x 0.8 = 0.64, i.e. a 36% total discount, not 40%.

3. Worked Examples

Example 1 — Finding CP from SP

A shopkeeper sells an item for $660 at a 10% profit. What was the cost price?

SP = CP x 1.10

CP = 660/1.10 = $600.

Trap: taking 10% off 660 gives 594, which is wrong because the 10% is based on CP, not SP.

Example 2 — Markup then discount

An item costing $400 is marked up by 50% and then sold at a 20% discount. What is the profit percent?

MP = 400 x 1.5 = $600.

SP = 600 x 0.8 = $480.

Profit = 480 - 400 = $80. Profit % = 80/400 x 100 = 20%.

Example 3 — The two-item classic

A trader sells two articles at $990 each, one at 10% profit and the other at 10% loss. What is the overall result?

  • First: CP = 990/1.10 = $900 -> profit $90.
  • Second: CP = 990/0.90 = $1,100 -> loss $110.

Total CP = $2,000; total SP = $1,980.

Net loss of $20, i.e. a 1% loss.

This is always a loss when the two percentages are equal — the loss percent is (x/10)^2 % , here (10/10)^2 = 1%.

4. GRE Traps

  • Computing profit % on SP instead of CP. The base is always CP.
  • Computing discount % on CP instead of MP. The base is always MP.
  • Adding successive discounts. 20% then 10% is 28%, not 30%.
  • Assuming equal profit and loss percentages cancel. They never do — the result is always a net loss (Example 3).
  • Confusing markup with profit. A 50% markup does not mean 50% profit if a discount follows.
  • Applying the discount before the markup. Follow the order in the sentence.

5. Speed Tricks

  • Set CP = 100. When the problem is all percentages, this turns it into arithmetic.
  • Use multipliers throughout. SP = CP x (1 + p) x (1 - d) handles the entire chain in one line.
  • CP = SP / multiplier for reverse problems — divide, never subtract.
  • Equal-percent profit-and-loss shortcut: net loss % = (x/10)^2, where x is the common percentage.
  • Sanity check: if the profit % came out larger than 100%, the SP must be more than double the CP. Verify.

6. Self-Check

Q1. An item costs $250 and sells for $300. What is the profit percent?

Q2. After a 25% discount, an item sells for $180. What was the marked price?

Q3. Successive discounts of 30% and 20% are equivalent to a single discount of what percent?

Answers

A1. Profit 50 on CP 250 -> 50/250 x 100 = 20%.

A2. MP x 0.75 = 180 -> MP = $240.

A3. 0.7 x 0.8 = 0.56, so the price is 56% of the original -> a 44% discount.

7. One-Line Summary for the Board

Profit % is on CP. Discount % is on MP. Successive discounts multiply, never add.
