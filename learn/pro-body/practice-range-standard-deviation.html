Q1 · STA-RSD-003 — Answer: C

Step 1 — recall the rule. SD = 0 happens only when every value is identical, because only then is every deviation from the mean equal to 0. Step 2 — scan the sets for one with a single repeated value. A - five different values. Spread out, SD > 0. B - four 0s and one 1. Not all identical, so SD > 0. C - every value is 7. Mean = 7, every deviation = 0, so SD = 0. D - mean = (-2 + 0 + 2 + 0 - 2)/5 = -2/5, and the values are not identical, so SD > 0. E - four 1s and one 2. Not identical, so SD > 0. Answer: C.

Trap. Picking B because the set is mostly zeros, or picking D because it looks symmetric about 0. The zeros in the set are values, not deviations; SD = 0 requires that all five values be the SAME number, whatever that number is.

Q2 · STA-RSD-008 — Answer: 25

Step 1 — range is a two-number question: find the largest value and the smallest value and stop. Maximum = 30, minimum = 5. Step 2 — range = max - min = 30 - 5 = 25. Answer: 25.

Trap. Reporting the count of values (6), the mean (17.5), or the common gap between consecutive terms (5). Range never depends on how many values there are or how they are spaced in between - only on the two extremes.

Q3 · STA-RSD-009 — Answer: C

SD is built from squared distances to the mean, then a square root, so it can never come out negative. A - false. {-5, -5, -5} has SD 0, and {-10, 0, 10} has SD > 0. Negative values never make the SD negative. B - false. {-2, 0, 2} has mean 0 but the values are not identical, so its SD is greater than 0. The mean says where the data sits, the SD says how scattered it is. C - true. SD >= 0 always, with equality exactly when every value is the same. D - false. For {0, 5, 10} the range is 10 but the SD is sqrt((25 + 0 + 25)/3) = sqrt(16.67) = 4.08, not 5. There is no fixed ratio between range and SD. E - false. Adding the same amount to every value slides the whole set along the number line; every distance from the mean is unchanged, so the SD is unchanged. Answer: C.

Trap. Choosing A because the data contains negative numbers, as if the SD inherited their sign. SD measures distance, and distance is never negative. E is the other live bait - it is the single most common standard-deviation error on the GRE, and it is false.

Q4 · STA-RSD-011 — Answer: C

Step 1 — recover the original maximum. Range = max - min, so max = range + min = 30 + 15 = 45. Step 2 — add 60. Since 60 > 45, the new value becomes the new maximum. The minimum is still 15, because 60 > 15. Step 3 — new range = 60 - 15 = 45. Check: the old range was 30, the maximum moved up from 45 to 60, and the minimum did not move, so the range should grow by exactly 15. 30 + 15 = 45. Correct. Answer: 45.

Trap. Answering 30 (choice B) by assuming one extra value cannot change the range - it does, because 60 sits outside the old span. Choice D, 60, reports the new maximum as if it were the range; choice E, 75, adds the minimum to 60 instead of subtracting it; choice A, 15, is 60 - 45, the amount the maximum moved rather than the new range.

Q5 · STA-RSD-012 — Answer: C

Step 1 — Set M: max = 9, min = 1, so range = 9 - 1 = 8. Step 2 — Set N is Set M with 7 added. Since 1 < 7 < 9, the new value is neither a new maximum nor a new minimum. Step 3 — Set N: max = 9, min = 1, so range = 9 - 1 = 8. Both ranges are 8, so the two quantities are equal. Answer: C.

Trap. Assuming that a fourth value must change the range, and picking B. A new value moves the range only if it lands outside the current maximum or minimum; anything strictly between them leaves the range alone. (Note the contrast with the standard deviation, which an interior value generally does change.)

Q6 · STA-RSD-022 — Answer: B

Do not compute five standard deviations. Use the capsule's test: find each mean, then judge the typical distance of the values from that mean. A - mean 30. Distances: 30, 0, 0, 0, 30. Average distance = 60/5 = 12. B - mean 20. Distances: 20, 20, 20, 30, 30. Average distance = 120/5 = 24. C - mean 30. Distances: 20, 10, 0, 10, 20. Average distance = 60/5 = 12. D - mean 31. Distances: 6, 6, 6, 6, 24. Average distance = 48/5 = 9.6. E - mean 30. Distances: 30, 15, 0, 15, 30. Average distance = 90/5 = 18. B has by far the largest typical distance from its mean, so B has the greatest SD. Check by actual computation: SD(A) = 18.97, SD(B) = 24.49, SD(C) = 14.14, SD(D) = 12.00, SD(E) = 21.21. B wins. Answer: B.

Trap. Choosing A or E because they have the largest range (60). A bigger range usually means a bigger SD, but it is not guaranteed: range is decided by only two values, while SD is decided by all of them. Set A has the widest span yet three of its five values sit exactly ON the mean, so its SD (18.97) is well below B's (24.49), even though B spans only 50.

Q7 · STA-RSD-023 — Answer: A

Step 1 — Column B first, because it is instant. Every value in B is 3, so all four values equal the mean and every deviation is 0. SD(B) = 0. Step 2 — Column A. Mean = (0 + 0 + 0 + 12)/4 = 3. The values are not all identical, so SD(A) > 0. That already settles it. Step 3 — for completeness: squared deviations are 9, 9, 9, and 81. Variance = (9 + 9 + 9 + 81)/4 = 108/4 = 27, so SD(A) = sqrt(27) = 5.20. 5.20 > 0, so Column A is greater. Answer: A.

Trap. Both sets have the same four-value count, the same sum (12) and the same mean (3), so students conclude the SDs match and pick C. Mean and sum say nothing about spread. The instant that one set has two different values in it and the other does not, the first set's SD is strictly larger - no arithmetic needed.

Q8 · STA-RSD-026 — Answer: C

Step 1 — spot the relationship between the sets. Every element of Q is 10 times the matching element of P, so Q = 10 x P. Step 2 — apply the scaling rule. Multiplying every value by k multiplies the SD by |k|, so SD(Q) = 10 x SD(P). Step 3 — Column B = SD(Q)/10 = 10 x SD(P)/10 = SD(P) = Column A. The two quantities are equal. Check by computing: P has mean 6 and squared deviations 16, 4, 0, 4, 16, so variance = 40/5 = 8 and SD(P) = sqrt(8) = 2.83. Q has mean 60 and variance 800, so SD(Q) = sqrt(800) = 28.28, and 28.28/10 = 2.83. Correct. Answer: C.

Trap. Treating the jump from P to Q as 'adding 18, 36, 54, ...' and concluding nothing can be said, or noticing only that Q's numbers are bigger and picking B. The two sets are related by a single multiplier, so the SD scales by exactly that multiplier and the division by 10 undoes it precisely.

Q9 · STA-RSD-027 — Answer: B

Step 1 — the mean. Adding 5 to every value adds 5 to the total for each of the n values, so the mean moves by exactly 5: new mean = 50 + 5 = 55. Step 2 — the spread. Adding the same constant to every value slides the whole set; the mean slides with it, so every deviation (value - mean) is unchanged. Squared deviations are unchanged, so the variance is unchanged: new variance = 16. Mean = 55, Variance = 16. Check with a tiny set: {2, 6} has mean 4 and variance ((-2)^2 + 2^2)/2 = 4. Add 5: {7, 11} has mean 9 and variance ((-2)^2 + 2^2)/2 = 4. The mean moved by 5; the variance did not move. Correct. Answer: B.

Trap. Choosing C by adding 5 to the variance as well as to the mean. Choice A makes the mirror-image error, updating the spread but not the location. Choice D, variance 400, comes from treating '+5' as 'times 5' (16 x 5^2 = 400); choice E does that to the mean too.

Q10 · STA-RSD-030 — Answer: 13

Step 1 — the original range, for orientation: 26 - 8 = 18. Step 2 — remove 26. The remaining values are 8, 12, 15, 19, 21. Removing the old maximum forces you to find the NEW maximum, which is 21. The minimum is still 8. Step 3 — new range = 21 - 8 = 13. Check: 8 and 21 are both in the reduced list and nothing lies outside them. Correct. Answer: 13.

Trap. Subtracting the removed value from the old range (18 - 26, or 26 - 18 = 8) instead of re-finding the extremes. Deleting the maximum does not shrink the range by the deleted value; it shrinks it by the gap between the old maximum and the next-largest value, here 26 - 21 = 5, giving 18 - 5 = 13.

Q11 · STA-RSD-031 — Answer: E

Step 1 — the scaling rule: multiplying every value by k multiplies the SD by |k|, not by k. The absolute value is there because SD is a distance and distances cannot be negative. Step 2 — here k = -2, so |k| = 2. Step 3 — new SD = 2 x 4 = 8. Check with a concrete set: {1, 5} has mean 3 and SD 2. Multiplying by -2 gives {-2, -10}, mean -6, deviations 4 and -4, so SD = 4 = |-2| x 2. Correct. Answer: 8.

Trap. Choosing A (-8) by carrying the minus sign through to the standard deviation. Multiplying by a negative reflects the data across the mean; it does not fold the spread inward or make it negative. Choice B, -4, is the half-corrected version of the same slip: seeing that multiplication cannot change the size of the spread, leaving the 4 alone, but still attaching the multiplier's minus sign. Choice D, 4, comes from treating multiplication like addition and leaving the SD alone entirely; choice C, 2, comes from dividing 4 by 2 because the multiplier is negative.

Q12 · STA-RSD-033 — Answer: 30

Handle the two operations in order, and remember only one of them can touch the SD. Step 1 — multiply every value by 5. Multiplying scales the SD by |5| = 5, so the SD becomes 5 x 6 = 30. Step 2 — add 3 to every value. Adding a constant slides the whole set and leaves the spread alone, so the SD stays at 30. Final SD = 30. Check with a two-value set: {0, 12} has mean 6 and SD 6. Apply 5x + 3: {3, 63}, mean 33, deviations -30 and 30, SD = 30. Correct. Answer: 30.

Trap. Carrying the '+3' into the answer and reporting 33. Only the multiplicative part of a transformation reaches the standard deviation. The mirror error is applying the +3 first, or ignoring the x5 and answering 6 - the two words to hold on to are 'adding shifts, multiplying scales'.

Q13 · STA-RSD-051 — Answer: A

Step 1 — express the boundary in standard deviations. 84 - 72 = 12, and 12/6 = 2, so 84 is exactly 2 SDs above the mean. Step 2 — use the 68-95-99.7 rule. About 95% of a normal distribution lies WITHIN 2 SDs of the mean, so about 100 - 95 = 5% lies outside that band. Step 3 — the bell curve is symmetric, so that 5% splits evenly between the two tails: 5/2 = 2.5% lies above 2 SDs and 2.5% below. About 2.5% of scores are greater than 84. Answer: A.

Trap. Answering 5% (choice B) by reporting the whole outside-2-SD region instead of just the upper tail - the question asks only for scores ABOVE 84. Choice C, 16%, is the same tail computed at 1 SD, (100 - 68)/2, and choice D, 32%, is the full outside-1-SD region. Choice E, 47.5%, is the area from the mean up to 84, which is the piece the question excludes.

Q14 · STA-RSD-034 — Answer: C

Step 1 — the mean. Mean = x + (0 + 4 + 8 + 12 + 16)/5 = x + 40/5 = x + 8. Step 2 — the deviations. Subtracting the mean from each term: x - (x + 8) = -8 (x + 4) - (x + 8) = -4 (x + 8) - (x + 8) = 0 (x + 12) - (x + 8) = 4 (x + 16) - (x + 8) = 8 The x cancels in every one of them, which is the whole point: the set is a fixed pattern shifted by x, and shifting never changes spread. Step 3 — squared deviations: 64, 16, 0, 16, 64. Their sum is 160. Step 4 — variance = 160/5 = 32, so SD = sqrt(32) = 4 x sqrt(2) = 5.66. Answer: sqrt(32).

Trap. Choosing E because x appears in all five terms. The x is an added constant, and adding a constant leaves the SD alone, so the answer is a fixed number. Choice D, sqrt(40), comes from dividing the sum of squared deviations by 4 instead of by 5 (the GRE uses the population SD, dividing by n). Choice A, 4, reports the common gap between consecutive terms, and choice B, 8, reports the largest single deviation.

Q15 · STA-RSD-035 — Answer: D

Set G has mean 4 and squared deviations 9, 4, 1, 0, 1, 4, 9, summing to 28, so variance = 28/7 = 4 and SD(G) = 2. The added value is unspecified, so test the extremes of what v may be. Case 1: v = 4, the mean. The mean of H is still (28 + 4)/8 = 4, and the new value contributes a squared deviation of 0. Variance(H) = 28/8 = 3.5, so SD(H) = sqrt(3.5) = 1.87 < 2. Column B is greater here. Case 2: v = 1, as far from the mean as v is allowed to go. H = {1, 1, 2, 3, 4, 5, 6, 7}, mean = 29/8 = 3.625. The squared deviations sum to 35.875, so variance = 35.875/8 = 4.484 and SD(H) = 2.118 > 2. Column A is greater here. The underlying rule: a new value pulls the SD DOWN if it sits closer to the mean than a typical member does, and pushes it UP if it sits further out. Here v = 2, 3, 4, 5, 6 all lower the SD and only v = 1 or v = 7 raise it.

Trap. Applying the 'adding a value at the mean lowers the SD' rule and keying B without noticing that v is not pinned to the mean - it is only pinned inside the interval [1, 7]. The opposite slip is assuming that any extra value must increase the SD and keying A. Both fail because v is only partly specified, and both cases genuinely occur.

Q16 · STA-RSD-036 — Answer: 17

The key is that b is invisible to the standard deviation, so the SDs alone determine a. Step 1 — use the standard deviations to find a. Multiplying by a scales the SD by |a|, and adding b does not change it, so new SD = |a| x old SD. 12 = |a| x 3, so |a| = 4, and since a > 0, a = 4. Step 2 — use the means to find b. Both operations move the mean: new mean = a x (old mean) + b. 57 = 4 x 10 + b 57 = 40 + b b = 17. Check: a value sitting 3 above the old mean, x = 13, becomes 4(13) + 17 = 69, which is 69 - 57 = 12 above the new mean - exactly one new SD, as it should be. Correct. Answer: 17.

Trap. Trying to find b from the standard deviations, for instance solving 12 = 3a + b or 12 = 3(a + b). The constant b never appears in the SD equation at all, which is precisely why the SDs isolate a first. Reversing the order - using the means to get a - leaves two unknowns in one equation and stalls.

Q17 · STA-RSD-037 — Answer: D

Step 1 — convert both boundaries into standard deviations from the mean. 162 = 170 - 8, so 162 is 1 SD BELOW the mean. 186 = 170 + 16 = 170 + 2(8), so 186 is 2 SDs ABOVE the mean. The interval is lopsided, so it cannot be read off the 68-95-99.7 rule in one step - split it at the mean. Step 2 — the piece below the mean. Q18 · STA-RSD-038 — Answer: B

Step 1 — set up the extreme case. SD does not change when the whole set slides, so take the smallest value to be 1; the range of 10 then forces the largest to be 11. Four more distinct integers must sit strictly between them. Step 2 — to push the SD as high as possible, drive every value as far from the centre as the distinctness rule allows: pack them against the two ends. The best arrangement is {1, 2, 3, 9, 10, 11}. Step 3 — evaluate it. Mean = (1 + 2 + 3 + 9 + 10 + 11)/6 = 36/6 = 6. Squared deviations: 25, 16, 9, 9, 16, 25. Sum = 100. Variance = 100/6 = 16.67, so SD = sqrt(16.67) = 4.08. Step 4 — compare. The greatest possible SD is about 4.08, which is less than 5, so Column B is greater. Answer: B. Why 5 is unreachable: even without the distinctness rule, the absolute ceiling on the SD of a set with range R is R/2 = 5, achieved only by putting every value at one of the two extremes. Six DISTINCT integers cannot do that, so the true maximum lands strictly below 5.

Trap. Reasoning that a range of 10 means values can be 5 from the centre, so the SD 'could be' 5, and keying C. Reaching R/2 would require every value to sit exactly at an endpoint; distinctness forces four of the six inward, which drags the average squared deviation down to 100/6 and the SD to 4.08. Keying D on the grounds that the values are unnamed is the other slip - the stem asks for a maximum, and the maximum is a definite number.

Q19 · STA-RSD-039 — Answer: A, C, D

A - every term is 10 more than the matching term of S, so this is S with the constant 10 added. Adding a constant leaves the SD unchanged. TRUE. B - every term is twice the matching term of S, so this is 2 x S. Multiplying scales the SD by |2|, giving 2 x sqrt(18) = sqrt(72) = 8.49. FALSE. C - the same five numbers, written in reverse order. A data set is a collection of values, not a sequence; order plays no part in the mean or in any deviation. SD unchanged. TRUE. D - every term is -1 times the matching term of S, so this is (-1) x S. Q20 · STA-RSD-040 — Answer: B

Break the new set into the two things that were done to the old one. Step 1 — subtract 3 from every value. That is adding the constant -3, which slides the whole set and changes no distance from the mean. {a - 3, b - 3, c - 3} still has SD 5. Step 2 — list every value twice. Doubling the list does not move the mean: the sum doubles and n doubles, so the mean is unchanged. Each squared deviation now appears twice, so the sum of squared deviations doubles while n also doubles - and variance is their quotient, so it is unchanged. In symbols, if the original squared deviations sum to T over n values, the new variance is 2T/(2n) = T/n, exactly the old variance. Step 3 — the SD is therefore still 5. Check with numbers: {1, 6, 11} has mean 6 and SD sqrt((25 + 0 + 25)/3) = 4.08. Then {-2, 3, 8, -2, 3, 8} has mean 3 and squared deviations 25, 0, 25, 25, 0, 25, so variance = 100/6 = 16.67 and SD = 4.08. Unchanged. Correct. Answer: 5.

Trap. Choice D, 10, comes from thinking that a data set with twice as many values must have twice the spread; choice A, 2, from subtracting the 3 from the SD as well as from the values. Choice C, 5 x sqrt(2), comes from applying a merge-two-groups formula as if these were two different groups - they are the same group listed twice, with identical means, so nothing is added. Choice E tempts anyone who thinks a, b and c must be known; every step here is a rule about spread, not about the actual values.

Q22 · STA-RSD-042 — Answer: C, D, E

Q23 · STA-RSD-043 — Answer: B

Step 1 — the mean does not move. New mean = (n x m + m)/(n + 1) = m(n + 1)/(n + 1) = m. Step 2 — the numerator of the variance does not move either. Variance is (sum of squared deviations)/n, so for the original set the sum of squared deviations is n x s^2. The added value equals the mean, so its deviation is 0 and it contributes 0 to that sum. The sum is still n x s^2. Step 3 — the denominator DOES move: there are now n + 1 values. New variance = n x s^2/(n + 1). Step 4 — since n/(n + 1) < 1 for every n > 0, the new variance is strictly less than s^2, so the new SD is strictly less than s. The standard deviation decreases. Check with numbers: {1, 2, 3} has mean 2 and variance (1 + 0 + 1)/3 = 0.667, SD = 0.816. Add the mean, 2: {1, 2, 3, 2} has mean 2 and variance (1 + 0 + 1 + 0)/4 = 0.5, SD = 0.707. Lower. Correct. Answer: B.

Trap. Choice A is the reflex that adding any data point must widen the spread; here the added point sits exactly at the mean, contributes 0 to the sum of squared deviations, and only enlarges the divisor, so the spread can only shrink. Choice C is chosen on the grounds that a value sitting exactly at the mean 'adds nothing'. It adds nothing to the TOP of the variance fraction but it still adds 1 to the BOTTOM, so the average squared deviation is spread over one more value and must fall. Choice D comes from confusing the new value's own deviation with the whole set's: that ONE value has deviation 0, but the other n values keep their deviations, so the sum of squared deviations stays at n x s^2 and the SD stays positive - it would reach 0 only if every value equalled m. Choice E is the last bait: the factor n/(n + 1) is less than 1 for every n, so the direction never depends on the size of n - only the size of the effect does.

Q25 · STA-RSD-045 — Answer: A, C
