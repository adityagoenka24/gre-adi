Part C — Worked Solutions

Q1 · ARI-P10-003 — Answer: D

Step 1 — read the negative exponent as a reciprocal, not as a sign: 10^(-n) = 1/10^n. Step 2 — 10^(-2) = 1/10^2 = 1/100 = 0.01. Step 3 — sanity check the sign of the exponent. A negative exponent always produces a number between 0 and 1, never a negative number. Answer: 0.01.

Trap. Choosing -100, which comes from carrying the minus sign into the value instead of into the exponent. Choice B, -0.01, is the half-corrected version: reciprocal taken but the sign kept. Choice E, 0.1, moves the decimal point only one place instead of two.

Q2 · ARI-P10-004 — Answer: -4

Step 1 — find the coefficient. The decimal point must land just after the first nonzero digit, so a = 5.6. Step 2 — count the places moved. Going from 0.00056 to 5.6 moves the point 4 places to the RIGHT. Step 3 — moving right makes the coefficient bigger, so the exponent must shrink to compensate: n = -4. Check: 5.6 x 10^(-4) = 5.6/10000 = 0.00056. Correct. Answer: -4.

Trap. Answering 4. The number is less than 1, so its exponent must be negative - a positive exponent would make 5.6 x 10^4 = 56,000. A second slip is answering -3 by counting only the zeros after the decimal point (three) instead of counting all the way to the first nonzero digit (four places).

Q3 · ARI-P10-005 — Answer: C

Step 1 — correct scientific notation is a x 10^k with the coefficient a satisfying 1 <= a < 10 and k an integer. Place the decimal point to meet that rule: a = 4.5. Step 2 — count places from 4.5 to 45,000: 4.5 -> 45 -> 450 -> 4,500 -> 45,000, four places to the left, so the exponent is 4. Step 3 — 45,000 = 4.5 x 10^4. Check: 4.5 x 10,000 = 45,000. Correct. Note that A (45) and D (0.45) also equal 45,000 but violate 1 <= a < 10, so neither is correct scientific notation.

Trap. Choices A and D are both numerically equal to 45,000 but neither is scientific notation: 45 is not less than 10 and 0.45 is not at least 1. Answer choices are always in proper standard form, so a coefficient outside [1, 10) is automatically wrong. Choice B, 4.5 x 10^3 = 4,500, moves the point one place too few; choice E, 4.5 x 10^5 = 450,000, one place too many.

Q4 · ARI-P10-009 — Answer: B

Step 1 — a positive exponent moves the decimal point to the RIGHT, one place per unit of the exponent. Step 2 — move the point in 2.4 six places right: 24 -> 240 -> 2,400 -> 24,000 -> 240,000 -> 2,400,000. Step 3 — as a place-value check, 10^6 is one million, so 2.4 x 10^6 is 2.4 million = 2,400,000. Answer: 2,400,000.

Trap. Choosing 240,000, which is 2.4 x 10^5 - the point was moved five places, not six. Choice C comes from appending six zeros to the digits '24' instead of moving the point six places from 2.4. Choice E moves the point in the wrong direction, which would require a negative exponent.

Q5 · ARI-P10-010 — Answer: A, B, C

First fix the target: 0.001 = 1/1000 = 10^(-3). A - 10^(-3) is exactly the target. TRUE. B - 1/10^3 = 1/1000 = 0.001. This is the definition of a negative exponent, so it is the same object as A. TRUE. C - multiplying powers of the same base ADDS exponents: 10^(-1) x 10^(-2) = 10^(-1 + -2) = 10^(-3) = 0.001. TRUE. D - this is addition, so exponents do not combine: 0.1 + 0.01 = 0.11. FALSE. E - 1/10^(-3) = 10^3 = 1000, because dividing by 10^(-3) is multiplying by 10^3. FALSE. Answer: A, B, C.

Trap. D is the live bait: students who have just learned that 10^(-1) x 10^(-2) = 10^(-3) apply the same move to a plus sign and get 0.001 again, when the true value is 0.11. E punishes the opposite carelessness - a reciprocal of a negative exponent flips it to positive, turning a thousandth into a thousand, a factor of a million away from the target.

Q6 · ARI-P10-012 — Answer: C

Step 1 — split the problem in two: coefficients with coefficients, powers with powers. Step 2 — coefficients: 5 x 4 = 20. Step 3 — powers: 10^3 x 10^6 = 10^(3+6) = 10^9. So far: 20 x 10^9. Step 4 — renormalise. Correct scientific notation requires the coefficient a to satisfy 1 <= a < 10, and 20 does not, so write 20 = 2 x 10^1 and absorb the extra power: 20 x 10^9 = 2 x 10^1 x 10^9 = 2 x 10^10. Check: 5,000 x 4,000,000 = 20,000,000,000 = 2 x 10^10. Correct.

Trap. Choice D, 20 x 10^9, is the right number in the wrong form - the arithmetic is finished but the renormalising step is skipped, and GRE options are always in proper standard form. Choice B is the mirror error: the coefficient is renormalised to 2 but the freed power of 10 is thrown away instead of being added to the exponent. Choice E multiplies the exponents (3 x 6 = 18) instead of adding them, and choice A adds the coefficients (5 + 4 = 9).

Q7 · ARI-P10-013 — Answer: 5

Alternative route, by moving the point: to turn 4.8 into 480,000 the decimal point travels 4.8 -> 48 -> 480 -> 4,800 -> 48,000 -> 480,000, which is five places to the left, so n = 5. Check: 4.8 x 100,000 = 480,000. Correct. Answer: 5.

Trap. Answering 4 by counting the zeros in 480,000. Zeros are not the exponent unless the coefficient is a single digit followed only by zeros. Here the leading digit 4 sits in the hundred-thousands place, which is 10^5, so five places of movement are needed even though only four zeros are visible.

Q8 · ARI-P10-014 — Answer: C

Step 1 — the outer power hits BOTH factors: (2 x 10^3)^2 = 2^2 x (10^3)^2. Step 2 — square the coefficient: 2^2 = 4. Step 3 — square the power: (10^3)^2 = 10^(3x2) = 10^6. Note that a power of a power MULTIPLIES the exponents. Step 4 — Column A = 4 x 10^6, which is exactly Column B. Check in full: 2,000^2 = 4,000,000 = 4 x 10^6. Correct. The two quantities are equal.

Trap. Squaring only the power of 10 and leaving the coefficient alone gives 2 x 10^6 = 2,000,000, which makes Column B look greater. The other slip is adding the exponents, (10^3)^2 = 10^5, which also points to Column B. Everything inside the bracket gets squared, and a power raised to a power multiplies.

Q9 · ARI-P10-016 — Answer: C

Column A: 10^(-3) = 1/10^3 = 1/1000 = 0.001. Column B: rewrite the base as a power of 10 first. 0.1 = 10^(-1), so (0.1)^3 = (10^(-1))^3 = 10^(-1 x 3) = 10^(-3). Both columns equal 0.001, so the two quantities are equal. Check by direct multiplication: 0.1 x 0.1 x 0.1 = 0.01 x 0.1 = 0.001. Correct.

Trap. Computing (0.1)^3 as 0.1 x 3 = 0.3, which makes Column B look much greater. Cubing a number between 0 and 1 makes it SMALLER, not larger. The reliable move is to convert every decimal to a power of 10 before doing anything else - once 0.1 becomes 10^(-1), the comparison is a one-line exponent calculation.

Q10 · ARI-P10-019 — Answer: A, C, E

The test is one line: a number has a negative exponent exactly when it is strictly between 0 and 1. A - 0.0083 = 8.3 x 10^(-3). Negative. TRUE. B - 8,300 = 8.3 x 10^3. Positive. FALSE. C - 0.83 = 8.3 x 10^(-1). It is less than 1, so the exponent is negative even though the number looks 'close to 1'. TRUE. D - 1 = 1 x 10^0. Zero is not negative, so this fails the test. FALSE. E - 0.00083 = 8.3 x 10^(-4). Negative. TRUE. Answer: A, C, E.

Trap. Missing C because 0.83 does not look small. Any number below 1 - even 0.99 - has a negative exponent. D is the boundary case: 1 = 1 x 10^0, and 10^0 = 1, not 0, so its exponent is zero, which is neither positive nor negative.

Q11 · ARI-P10-021 — Answer: B

Check: 0.00072 < 0.00083 < 0.00091. Correct.

Trap. Choice D comes from comparing the exponents exactly as printed, -6 < -4 < -3, which puts Z smallest and X largest - the reverse of the truth for X. That shortcut is only legal once every coefficient is in [1, 10). Choice A comes from ranking by coefficient alone (0.72 < 9.1 < 830), choice C from renormalising X and Y but leaving Z at 10^(-6) and assuming it must therefore be the smallest, and choice E is the correct ranking written greatest-to-least when least-to-greatest was asked.

Q12 · ARI-P10-022 — Answer: 395

Step 1 — 'how many times as far' means divide, so form (1.5 x 10^8)/(3.8 x 10^5). Step 2 — split it: coefficients divide, exponents subtract. coefficients: 1.5/3.8 = 0.3947... exponents: 10^(8-5) = 10^3 Step 3 — 0.3947 x 10^3 = 394.7... Step 4 — round: 395. Order-of-magnitude sanity check: 1.5/3.8 is a bit under 0.4, and 0.4 x 1,000 = 400, so the answer must be a three-digit number just under 400. Correct. Answer: 395.

Trap. Subtracting the exponents in the wrong order, 10^(5-8) = 10^(-3), which gives 0.395 - a Sun closer than the Moon, which the sanity check kills instantly. The dividend's exponent comes first. The other slip is reading 0.3947 x 10^3 as 3.947 or as 39.47 by mis-shifting the point.

Q13 · ARI-P10-025 — Answer: A, C, E

A - a power of a power multiplies exponents: (10^2)^3 = 10^(2x3) = 10^6. TRUE. B - division subtracts exponents: 10^12/10^2 = 10^(12-2) = 10^10, not 10^6. FALSE. C - multiplication adds exponents, and a negative exponent is just a negative addend: 10^8 x 10^(-2) = 10^(8 + (-2)) = 10^6. TRUE. D - addition does not touch exponents at all: 10^3 + 10^3 = 2 x 10^3 = 2,000. FALSE. E - multiply the exponents, keeping both signs: (10^(-2))^(-3) = 10^((-2)x(-3)) = 10^6. TRUE. Answer: A, C, E.

Trap. B is the sharpest bait: 12/2 = 6, so dividing the exponents lands on the target by an illegal route - division of same-base powers subtracts, giving 10^10. D catches the belief that adding two equal powers combines their exponents; it only doubles the coefficient, leaving 2,000. E is dropped by students who see two minus signs and expect a small number, when two negatives multiply to a positive exponent.

Q14 · ARI-P10-027 — Answer: C

Step 3 — convert an order of magnitude into a digit count. 10^12 is a 1 followed by 12 zeros, which is 13 characters, so any number of size about 10^12 has 13 digits. The general rule: a positive integer N with 10^(k) <= N < 10^(k+1) has k + 1 digits. Check against the true value: 2^40 = 1,099,511,627,776, which indeed has 13 digits. Correct.

Trap. Choice B, 12, reads the exponent itself as the digit count; the count is always exponent + 1 for a number of size 10^k. Choice D applies that same 'exponent + 1' rule to the wrong exponent, the 40 in 2^40. Choice E comes from attaching the outer power to the approximation as (10^3)^40 = 10^120 and then adding 1, and choice A reads the outer exponent 4 as the answer.

Q15 · ARI-P10-028 — Answer: 11

The insight: never solve for x and y separately. An exponent sum becomes a product. Step 1 — 10^(x+y) = 10^x x 10^y. Step 2 — substitute the two given values: 10^(x+y) = (5 x 10^7)(2 x 10^3) Step 3 — coefficients multiply, exponents add: (5 x 2) x 10^(7+3) = 10 x 10^10. Step 4 — renormalise: 10 x 10^10 = 10^1 x 10^10 = 10^11. Step 5 — since 10^(x+y) = 10^11 and the bases match, x + y = 11 exactly. Answer: 11.

Trap. The setup is engineered so the coefficients multiply to exactly 10; a student who writes 10 x 10^10 and reads off the exponent answers 10. That extra factor of 10 must be folded in, pushing the exponent to 11. The other route - x = log(5) + 7 = 7.699 and y = log(2) + 3 = 3.301 - is slow and invites rounding error, and no logarithm is needed here.

Moving from 10^(-5) up to 10^(-4) raises the exponent by 1, so the coefficient must shrink by a factor of 10: 2 x 10^(-5) = 0.2 x 10^(-4) Step 2 — subtract the coefficients: (3 - 0.2) x 10^(-4) = 2.8 x 10^(-4). Step 3 — that is exactly Column B, so the two quantities are equal. Check in decimals: 0.0003 - 0.00002 = 0.00028 = 2.8 x 10^(-4). Correct.

Trap. Subtracting the coefficients as they stand, 3 - 2 = 1, and reporting 1 x 10^(-4) or 1 x 10^(-5) - both make Column B look greater. The exponents are one apart, so 2 x 10^(-5) is only a tenth of a unit of 10^(-4), not two units. Q20 · ARI-P10-033 — Answer: C

Step 1 — Column A is a sum of like terms. Factor out 10^n: 9 x 10^n + 10^n = (9 + 1) x 10^n = 10 x 10^n Step 2 — renormalise the coefficient 10, which is 10^1: 10 x 10^n = 10^1 x 10^n = 10^(n+1) Step 3 — that is exactly Column B, and no step used the value of n, so the two quantities are equal for every positive integer n. Check with n = 3: Column A = 9,000 + 1,000 = 10,000; Column B = 10^4 = 10,000. Correct.

Trap. Assuming Column A must be smaller because 9 + 1 is only 10 while Column B is a whole extra power of ten - it is exactly the same thing, since ten copies of 10^n IS 10^(n+1). The opposite error is treating the sum as an exponent operation, 10^n + 10^n = 10^(2n), which would make Column A explode and point to A. Addition of like powers changes only the coefficient. Because the identity holds for every n, D is also wrong.

Q21 · ARI-P10-034 — Answer: D

Step 1 — get the ratio first; in scientific notation this is one line. A/B = (2.1 x 10^13)/(1.4 x 10^12) = (2.1/1.4) x 10^(13-12) = 1.5 x 10^1 = 15 So A is 15 times B. Q22 · ARI-P10-035 — Answer: 4

The insight: translate the exponent arithmetic into ordinary arithmetic on the given values. No logarithms are needed. Step 1 — a sum in the exponent becomes a product: 10^(a + 2b) = 10^a x 10^(2b). Step 2 — a multiple in the exponent becomes a power: 10^(2b) = (10^b)^2 = (0.25)^2 = 0.0625. Step 3 — multiply the two known pieces: 10^(a+2b) = 64 x 0.0625. Step 4 — 0.0625 = 1/16, so 64 x 1/16 = 4. Answer: 4.

Trap. Doubling the value instead of squaring it - reading 10^(2b) as 2 x 10^b = 0.5, which gives 64 x 0.5 = 32. The 2 multiplies the EXPONENT, so it becomes a square on the value. The slow alternative, a = log(64) = 1.806 and b = log(0.25) = -0.602, then 10^(1.806 - 1.204) = 10^0.602, is both tedious and vulnerable to rounding.

Q28 · ARI-P10-039 — Answer: D

The stem allows q = 0, and that boundary case reverses the comparison. Test both regions. Case 1 - q = 0. Then Column A = 10^p - 1 and Column B = 10^(p-0) = 10^p. Subtracting 1 from 10^p leaves something strictly smaller than 10^p, so Column B is greater. Example: p = 3, q = 0 gives A = 1,000 - 1 = 999 and B = 1,000. Column B wins. Case 2 - q >= 1. Factor Column A: 10^p - 10^q = 10^q(10^(p-q) - 1). Write m = p - q >= 1. Then Column A = 10^q x (10^m - 1) >= 10 x (10^m - 1) = 10^(m+1) - 10 and since m >= 1, 10^(m+1) - 10 >= 10^m x 10 - 10 > 10^m = Column B. Example: p = 3, q = 1 gives A = 1,000 - 10 = 990 and B = 10^2 = 100. Column A wins. Both outcomes occur, so the relationship cannot be determined.

Trap. Testing only q = 1, 2, 3 - where Column A always wins by a wide margin - and confidently choosing A. The single case q = 0 flips it, because then Column B stops being a small leftover and becomes the full 10^p, one unit above Column A. On any QC with 'nonnegative', deliberately test the value 0 before committing.

Q29 · ARI-P10-040 — Answer: A, C, D

Write S out first - the powers of 10 stack into a single pattern of 1s. S = 10 + 100 + 1,000 + ... + 1,000,000,000 = 1,111,111,110 (nine 1s followed by one 0). A - 10^10 = 10,000,000,000, and S = 1,111,111,110 is well below it. TRUE. B - S = 1.11111111 x 10^9, which is LESS than 1.2 x 10^9. FALSE. C - S has nine 1s and a final 0, so 10 digits. Equivalently 10^9 <= S < 10^10, and any such integer has 10 digits. TRUE. D - the digits are nine 1s and one 0, summing to 9. TRUE. E - the correct closed form is S = 10(10^9 - 1)/9 = (10^10 - 10)/9. The option has 10^9 where 10^10 belongs: (10^9 - 10)/9 = 999,999,990/9 = 111,111,110, which is S with one term missing. FALSE. Answer: A, C, D.

Trap. B is the estimation bait: nine terms each 'about a billion' feels like several billion, but the series is dominated by its single largest term - everything below 10^9 adds only about 11% more, so S sits just past 1.11 x 10^9, not past 1.2 x 10^9. Q30 · ARI-P10-043 — Answer: C

Reduce each bound to a clean power of 10 before counting anything. Step 1 — lower bound. Coefficients: 2.5 x 4 = 10. Exponents: -4 + (-3) = -7. Raw result 10 x 10^(-7), and renormalising gives exactly 10^(-6). Step 2 — upper bound. The square hits both factors: (5 x 10^6)^2 = 5^2 x 10^12 = 25 x 10^12 = 2.5 x 10^13. Step 3 — the condition is 10^(-6) < 10^n < 2.5 x 10^13. Step 4 — the left inequality is strict and the lower bound is exactly 10^(-6), so n = -6 is excluded and the smallest allowed n is -5. Step 5 — on the right, 10^13 = 1 x 10^13 < 2.5 x 10^13, so n = 13 qualifies, while 10^14 = 10 x 10^13 does not. The largest allowed n is 13. Step 6 — count the integers from -5 to 13 inclusive: 13 - (-5) + 1 = 19. Answer: 19.

Trap. The lower bound is engineered to be exactly a power of 10 - 2.5 x 4 = 10 renormalises 10^(-7) up to 10^(-6) - so a student who treats the inequality as inclusive counts n = -6 as well and answers 20 (choice D). Choice E adds n = 14 on top of that, from reading the upper bound 2.5 x 10^13 as if it reached 10^14. Choice B is the count from -5 to 13 with n = 0 accidentally skipped, the standard off-by-one when a range straddles zero, and choice A counts only n = 0 through 13, forgetting that powers of 10 below 1 are also in range.
