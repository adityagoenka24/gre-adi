Q1 · NUM-EOP-002 — Answer: B

Test each option with the parity table. Use p = 2 and q = 3 to keep it concrete, but the rule is what decides. A - even + odd = odd. With p = 2, q = 3: 5. FALSE. B - even x anything = even, so p x q is even. With p = 2, q = 3: 6. TRUE. C - p + p = even, and even + odd = odd. With p = 2, q = 3: 7. FALSE. D - odd + odd = even, then even + odd = odd. With q = 3: 9. FALSE. E - p x q is even, and even + odd = odd. With p = 2, q = 3: 9. FALSE. Check with a second pair, p = 4 and q = 7: A = 11 odd, B = 28 even, C = 15 odd, D = 21 odd, E = 35 odd. Same verdicts. Answer: B.

Trap. Choosing D on the belief that odd + odd + odd is even. The first two odds do pair up to an even, but the third odd flips it back: 3 + 3 + 3 = 9. Choosing C or E comes from forgetting that adding an odd number always changes parity.

Q2 · NUM-EOP-004 — Answer: 1

Step 1 — find the parity of the sum. even + odd = odd, so x + y is odd. Step 2 — translate parity into a remainder. An odd integer is 2k + 1, so dividing it by 2 leaves remainder 1; an even integer would leave remainder 0. Check with x = 4, y = 3: 7 divided by 2 is 3 remainder 1. Check with x = 0, y = -5: -5 = 2 x (-3) + 1, remainder 1 again. Answer: 1.

Trap. Answering 0 by treating 'x + y' as a sum of two integers and assuming any such sum is even. The answer is also not 0.5: a remainder is a whole number left over, not the fractional part of the quotient.

Q3 · NUM-EOP-008 — Answer: 7

Step 1 — list them. The even integers in the range are -6, -4, -2, 0, 2, 4, 6. Step 2 — count: that is 7 integers. Two points decide this question. Zero is even, because 0 = 2 x 0, so it belongs on the list. Negative integers have parity too, so -6, -4 and -2 belong as well. Check by the endpoint formula: from -6 to 6 the evens are spaced 2 apart, giving (6 - (-6))/2 + 1 = 12/2 + 1 = 7. The extra integer 7 is odd and adds nothing. Answer: 7.

Trap. Answering 6 by skipping 0 as 'neither even nor odd'. Answering 3 by counting only the positive evens 2, 4 and 6 and discarding the negatives, which is the 'not even means positive odd' habit in reverse.

Q4 · NUM-EOP-010 — Answer: D

Q5 · NUM-EOP-011 — Answer: B, C, D

Step 2 — so the expression is even exactly when n is even. The signs do not matter: subtraction obeys the same parity table as addition. A - n = 3 is odd. 27 - 9 + 3 = 21, odd. FALSE. B - n = 4 is even. 64 - 16 + 4 = 52, even. TRUE. C - n = -2 is even; the minus sign does not change parity. -8 - 4 - 2 = -14, even. TRUE. D - n = 0 is even, since 0 = 2 x 0. 0 - 0 + 0 = 0, even. TRUE. E - n = 7 is odd. 343 - 49 + 7 = 301, odd. FALSE. Check: the three selected values 4, -2 and 0 are exactly the even entries in the list. Answer: B, C, D.

Trap. Skipping C because -2 is negative and skipping D because 0 looks like a special case. Both are even integers: parity is about divisibility by 2, not about sign, and 0 divided by 2 leaves remainder 0. The other slip is treating the three terms as if the minus sign could flip a parity, and then selecting A or E because 'two odds and a subtraction' feels even; subtraction follows the same table as addition, so the expression simply inherits the parity of n.

Q6 · NUM-EOP-014 — Answer: C

B - a x b is even, b is odd; even + odd = odd. FALSE. C - a^2 x b is even, a is even; even + even = even. TRUE. D - a x b is even, b is odd, a is even; even + odd + even = odd. FALSE. Trap. Choosing A or E because squaring feels like it should produce an even result on its own. Squaring never changes parity: b^2 is still odd when b is odd, so a^2 x b + b and a^2 x b^2 + b both end as even + odd = odd. The parity of a sum is decided by the odd terms only.

Q7 · NUM-EOP-017 — Answer: B

Step 1 — m - n is even, and a difference is even only when the two terms share a parity. So m and n are both odd or both even. Step 2 — m x n is even, and a product is odd only when every factor is odd. So m and n are not both odd. Step 3 — combining the two, m and n are both even. Write m = 2j and n = 2k. A - m + n = 2j + 2k = 2(j + k), which is even but need not be a multiple of 4: m = 2, n = 4 gives 6. FALSE. B - m x n = 4jk, which is always a multiple of 4. TRUE. C - both odd would make m x n odd, which the stem forbids. FALSE. D - both even makes m + n even, never odd. FALSE. E - m/2 + n/2 = j + k, and j and k have no forced parity: m = 2, n = 4 gives 1 + 2 = 3, odd. FALSE. Check with m = 6 and n = 10: m - n = -4 even, m x n = 60 even, and 60 = 4 x 15 is a multiple of 4. Check with m = 2 and n = 4: 8 = 4 x 2. Correct. Answer: B.

Trap. Choosing C stops at the first condition: m - n even does mean m and n share a parity, and 'both odd' is the case students reach for first, but it is killed by m x n being even. Choosing A promotes 'the sum of two evens' to 'a multiple of 4'; 2 + 4 = 6 is the counterexample. Choosing E applies parity rules through division: halving two even numbers says nothing about the parity of the halves, since 2/2 = 1 is odd while 4/2 = 2 is even.

Q15 · NUM-EOP-029 — Answer: C

The key identity is that n^2 + n = n(n + 1) is a product of two consecutive integers, so it is always even. The same argument handles the cubes, since n^3 has the same parity as n. A - n^3 has the parity of n, so n^3 + n is odd + odd = even when n is odd and even + even = even when n is even. Always even. FALSE. B - n^3 + n^2 = n^2(n + 1), a product in which n and n + 1 are consecutive, so one factor is even. With n = 3: 27 + 9 = 36, even. FALSE. C - n^3 + n is always even by A, so adding 1 makes it always odd. With n = 2: 8 + 2 + 1 = 11; with n = 3: 27 + 3 + 1 = 31; with n = -2: -8 - 2 + 1 = -9. TRUE. D - n^3 - n = (n - 1)n(n + 1), three consecutive integers, so it is always even (in fact always divisible by 6). With n = 3: 24. FALSE. E - factor it: n^3 + n^2 + n + 1 = n^2(n + 1) + (n + 1) = (n^2 + 1)(n + 1). With n = 2: 8 + 4 + 2 + 1 = 15, odd; with n = 3: 27 + 9 + 3 + 1 = 40, even. Odd for some n but not all. FALSE. Check C at n = 0: 0 + 0 + 1 = 1, odd. Correct. Answer: C.

Trap. Choosing E is the designed trap: testing a single even value such as n = 2 gives 15, which is odd, and the pattern looks settled.
