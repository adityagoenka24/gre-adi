2. Must-Know Rules

Concept Formula / Fact
Slope between two points (y2 - y1)/(x2 - x1)
Slope-intercept form y = mx + b (m = slope, b = y-intercept)
Horizontal line slope 0, equation y = c
Vertical line slope undefined, equation x = c
y-intercept the y value where x = 0
x-intercept the x value where y = 0

Reading the sign:

Slope Line
positive rises left to right
negative falls left to right
zero horizontal
undefined vertical

Steepness: the larger the absolute value of the slope, the steeper the line. A slope of -4 is steeper than a slope of 2.

Slope is constant along a line. Any two points on the same line give the same slope — which is exactly how you test whether three points are collinear.

3. Worked Examples

Example 1 — Slope from two points

Find the slope of the line through (2, -3) and (8, 9).

m = (9 - (-3))/(8 - 2) = 12/6 = 2.

Example 2 — Intercepts

For the line 3x + 4y = 24, find both intercepts and the slope.

x-intercept: set y = 0 -> 3x = 24 -> x = 8, so (8, 0).

y-intercept: set x = 0 -> 4y = 24 -> y = 6, so (0, 6).

Slope: rewrite as y = -3x/4 + 6, so m = -3/4.

(Or use the two intercepts: (6 - 0)/(0 - 8) = -3/4. Same.)

Example 3 — Collinearity

Are (1, 2), (3, 6) and (6, 12) collinear?

Slope from the first to the second: (6-2)/(3-1) = 2.

Slope from the second to the third: (12-6)/(6-3) = 2.

Same slope through a shared point, so yes, they are collinear.

4. GRE Traps

  • Inverting the formula. It is rise over run — the change in y on top.
  • Mismatched order. Whatever order you use for y, use the same for x. (y2-y1)/(x1-x2) is wrong.
  • Vertical line slope = 0. No — a horizontal line has slope 0; a vertical line's slope is undefined.
  • Negative slope confused with a small slope. -5 is a steep line; 0.1 is nearly flat.
  • Reading the y-intercept off an unsimplified equation. For 2y = 6x + 10, the intercept is 5, not 10.
  • Assuming the graph's visual steepness matches the slope value when the axes have different scales.

5. Speed Tricks

  • Rewrite everything in y = mx + b form. Slope and intercept then read straight off.
  • For Ax + By = C, slope = -A/B and the y-intercept is C/B. Instant.
  • For intercepts, cover the other variable: set y = 0 for the x-intercept and x = 0 for the y-intercept.
  • Sketch two points to confirm the sign of the slope before trusting your arithmetic.
  • Equal slopes plus a shared point means collinear. Equal slopes with no shared point means parallel.

6. Self-Check

Q1. Find the slope through (-2, 5) and (4, -7).

Q2. What are the intercepts of 5x - 2y = 20?

Q3. What is the slope of the line x = 7?

Answers

A1. (-7 - 5)/(4 - (-2)) = -12/6 = -2.

A2. x-intercept (4, 0); y-intercept (0, -10).

A3. It is a vertical line, so the slope is undefined.

7. One-Line Summary for the Board

Slope = rise over run. Horizontal is 0, vertical is undefined. For Ax + By = C, slope = -A/B.
